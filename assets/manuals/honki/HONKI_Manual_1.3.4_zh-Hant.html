1. 總覽

HONKI 是 iPad 上的八軌樂句產生器與音源系統。一個 pattern 有 8 個 track，每個 track 各有 8 個 segment 記憶槽。

頂列的六個分頁按鈕：MAIN、VOICE、MIXER、UTILITY、PERFORM、VISUAL。圖中 MAIN 為目前分頁。

Track 結構

TRACK 1 至 4旋律軌。在 MAIN 的 TRACK 1 至 4 編輯器編輯音符。
TRACK 5 至 8鼓軌。在 MIXER 與 PERFORM 顯示為 FOUNDATION、GROOVE、TIMELINE、LEAD。在 MAIN 的 DRUMS 編輯器編輯。
角色配對TRACK 1 與 5 為 foundation，2 與 6 為 groove，3 與 7 為 timeline，4 與 8 為 lead。
Segment每個 track 有 8 個 segment 槽。播放方式有 SINGLE、SEQUENCER、RANDOM 三種，鼓軌另有 FOLLOW。
音域預設MIDI 音高 36 至 72。
音源每軌四選一：SYNTH、SAMPLE、PHYSICAL、AU。

六個分頁

MAIN樂句編輯與 segment 管理。啟動時的起始分頁。
VOICE音源選擇與參數。
MIXER八軌混音、EQ、壓縮、效果送出、主效果。
UTILITY8 段包絡、LFO、CV 輸出矩陣。
PERFORM自訂控制面板與對應。
VISUAL影像來源與四個影像處理站。

切換分頁：點頂列分頁按鈕，或用外接鍵盤數字鍵 1 至 6。編輯覆蓋層開啟時，數字鍵改為切換 TRACK 1 至 4 與 DRUMS。分頁切換可指定 MIDI Learn。雙指滑動切換分頁已移除。

標題位置

頂列最右的方形按鈕切換標題所在角落，順序為左上、右上、左下、右下。標題在下方時，Transport 列移到畫面上方。

專案槽

槽位數26 個 bank（A 至 Z），每個 bank 10 個 pattern（00 至 09）。槽位 ID 格式為 A-00。
每槽儲存內容bank、programs、modulation、PERFORM 版面、MASTER FX、各軌 AU。
全 app 共用（不隨槽位）INPUT COMP、HUE、CV 裝置綁定。
啟動時回復上次使用的槽位。

Undo

Undo 以整個 bank 的快照為單位，最多 100 步。同一 tick 內的多次修改合併為一步，拖曳過程合併為一步。MIDI Learn 寫入、TAP tempo、載入 bank 不進入 undo。

2. 頂列

頂列：左側為計時器（圖中顯示 00:06）與「Click Twice to Reset」提示，接著 MADZINE 字樣、A-00 槽位選單、FILE 選單、六個分頁按鈕（MAIN 為目前分頁），最右為標題角落按鈕。
計時器啟動時顯示「H O N K I」。第一次按 PLAY 並回答錄音確認（Y 或 N）後開始計時，格式 MM:SS。點兩下歸零，旁邊顯示「Click Twice to Reset」提示。
MADZINE品牌文字。
A-00 選單兩層選單。第一層最上方為 CLEAR，之後是 bank A 至 Z；第二層是 pattern 00 至 09。可指定 MIDI Learn 為「下一個 bank」。
CLEAR若 bank 有內容，先詢問「Clear everything?」。清除 bank、programs、SWING 與 TRANSPOSE 歸 0、modulation、PERFORM 版面、MIDI 綁定、各軌 AU、MASTER FX、CV 路由。保留 INPUT COMP、HUE、CV 裝置與 STEREO OUT。
FILE 選單COPY、PASTE、SAVE、LOAD，以及不可點的 VERSION 項目（顯示版本號）。PASTE 只在剪貼簿非空時可用。
SAVE匯出 .honki 檔。iOS 預設檔名為「HONKI 槽位」。
LOAD匯入 .honki 檔。詢問「Replace current bank?」「Current changes will be lost.」。失敗時顯示「Bank File Error」。
分頁按鈕六個，見第 1 章。
角落按鈕右端方形按鈕，顯示目前標題角落。點一下依序輪換。

.honki 檔案

目前檔案格式包含 bank、programs、各軌 AU、MASTER FX、modulation、PERFORM 版面。可匯入舊版本的 .honki 檔與純 bank 檔。

3. Transport

Transport 列由左至右：STOP（圖中為播放中，顯示方形圖示）、MOTION、RESET、BPM 132、TAP、音階按鈕 C Minor、SWING 0（灰顯）、STYLE 選單 TECHNO、SETUP、LEARN、上下排列的 UNDO 與 REDO，最右為 HUE 色圈。
PLAY / STOP未進入錄音狀態時按 PLAY，按鈕內出現 Y、REC?、N 三段，5 秒後自動收起。Y 為錄音並播放，N 為只播放。播放中按鈕顯示 STOP。可指定 MIDI Learn。
錄音停止按鈕只在錄音狀態顯示，為紅點膠囊按鈕，位於 PLAY 左側。按下出現「STOP RECORDING?」Y / N，5 秒後自動關閉。停止後產生 9 個 WAV 檔，見第 14 章。
MOTION切換 MOTION 記錄狀態。長按 0.6 秒刪除所有 MOTION 記錄。不可指定 MIDI Learn。見第 13 章。
RESET只在播放中可用，將播放位置歸零。可指定 MIDI Learn。
BPM20 至 300。垂直拖曳調整，點一下輸入數字。使用外部時脈時灰顯 40%。可指定 MIDI Learn。
TAP2 秒視窗內最多 4 次點擊取平均。最後一次點擊 5 秒後清除緩衝。不進入 undo。外部時脈時不可用。
SCALE兩層選單：第一層音階，第二層 12 個根音。按鈕顯示根音與音階名。內建 16 種：Chromatic、Major、Minor、Penta Major、Penta Minor、Dorian、Phrygian、Lydian、Mixolydian、Locrian、Major Triad、Minor Triad、Blues、Arabic、Japanese、Whole Tone；之後列出使用者音階與 USER SCALE EDITOR。選單以星號數量標示目前 STYLE 的推薦程度。
SWING填滿式橫向 fader，0 至 100。點兩下回到 0.5。奇數步延後 stepDuration x 0.25 x swing。可指定 MIDI Learn。
STYLE彈窗內有 AMOUNT 旋鈕（0 至 1）與 9 種風格，兩欄排列：West African、Afro-Cuban、Brazilian、Balkan、Indian、Gamelan、Electronic、Breakbeat、Techno。AMOUNT 與風格索引皆可指定 MIDI Learn。
SETUP開關 SETUP 覆蓋層。見第 11 章。
LEARN開關 MIDI Learn 模式，文字在 LEARN / LEARNING 之間切換。快捷鍵 Cmd+L。可指定的控件會出現 4pt 外框。
UNDO / REDO無可復原內容時灰顯 40%。快捷鍵 Cmd+Z、Cmd+Shift+Z。PERFORM 版面編輯使用 PERFORM 自己的 undo 堆疊。
HUE「HUE」文字與色圈。彈窗標題「ACCENT HUE」：外環拖曳改色相，中央圓盤垂直拖曳改飽和度（0 至 2）。

USER SCALE EDITOR

CLOSE關閉編輯表單。
SCALE NAME音階名稱輸入欄。
音級按鈕12 個，2 列 6 欄，相對於全域 ROOT。預設包含根音。
音程摘要顯示已選音程；未選任何音級時顯示「SELECT AT LEAST ONE PITCH CLASS」。
SAVE NEW SCALE / SAVE CHANGES新增或儲存修改。
CANCEL EDIT取消目前編輯。
SAVED USER SCALES已存音階清單，空時顯示「No user scales saved yet.」。每項有 SELECT、EDIT、DELETE。刪除使用中的音階時，全域音階回到 Chromatic。

4. MAIN

MAIN 全頁。上方為 track 分頁列與參數列；左欄為 MASTER TRANSPOSE、MASTER LOCK / DECAY / DENSITY 旋鈕、RANGE / PITCH / KEYS 切換與 8 條 track 條；右側為嵌入的樂句編輯器，含小節列、START / END 列、HIGH C5 / LOW C3、SEMI 與 OCTAVE 按鈕、IMPORT MIDI、LOCK / CLEAR、COPY / PASTE、PHRASE FLIP 與 RATIO 1x、GLOBAL Minor 音階選單、VEL / PROB / PITCH 切換與音符格。

Track 分頁列

Track 分頁列：兩端各一個斜向箭頭全螢幕按鈕，MULTI、S、提示文字（長按靜音、點兩下獨奏），以及 1-1 至 8-1 八個 track 分頁（圖中 1-1 為目前 track），每個分頁上方有色點。
全螢幕按鈕列兩端各一個斜向箭頭按鈕，開啟或關閉編輯器全螢幕。
MULTI多軌同步編輯。開啟時，被同步的旋鈕顯示虛線環。
S清除所有 track 的 solo。
Track 分頁點一下選擇 track；0.35 秒內點兩下切換 SOLO；長按 0.45 秒切換 MUTE。分頁文字為 track 編號與目前 segment（例如 1-1）。

參數列

參數列：MUTE、SOLO、P（program 選單）、LOCK / DECAY / DENSITY 三個旋鈕、segment 1 至 8（圖中 1 為目前 segment）、SINGLE / SEQUENCER / RANDOM 播放模式。
MUTE / SOLO目前 track 的靜音與獨奏。
PProgram 選單：SAVE、LOAD、CLEAR，對象為 Program 1 至 8。
LOCK0 至 100%，垂直拖曳，無點兩下重設。
DECAY旋律軌顯示為 0 至 100%，內部範圍 -0.99 至 0.99；鼓軌範圍 0.2 至 2.0（1.0 顯示為 44%）。點兩下重設（鼓軌 1.0，旋律軌 -0.78）。
DENSITY0 至 100%。點兩下清除 segment 的覆寫值。
Segment 1 至 8三種狀態：無、空、有內容。有 RATIO 時顯示標籤。鏈狀態顯示在底部 3pt 條，播放中在頂部顯示 3pt 線。點擊優先順序：鏈設定中 > RANDOM 池 > MULTI > 選擇。
SINGLE只播放目前 segment，顯示 SEG n。
SEQUENCER依序點 START、起點槽、END、終點槽，之後顯示 SEQ a-b。
RANDOM顯示 CHOOSE，點槽位加入或移出隨機池。
FOLLOW鼓軌專用，跟隨配對旋律軌的 segment。

左欄

左欄：MASTER TRANSPOSE 的 -、0、+ 按鈕，MASTER LOCK / DECAY / DENSITY 旋鈕，RANGE / PITCH / KEYS 切換，之後是 8 條 track 條（標示 1 至 8 與 SEG 1），每條上方有步數刻度 1 / 5 / 9 / 13 與音符名稱。圖中 track 1 有外框表示為目前 track，直向外框為播放位置。
MASTER TRANSPOSE-、0、+ 三個按鈕，範圍 ±24 半音。
MASTER LOCK / DECAY / DENSITY同時寫入全部 8 軌的對應參數。
RANGE拖曳每條 track 條的兩端把手，設定播放視窗的起點與終點。
PITCH點一格切換音符（音高為音域中點，力度 100，gate 0.5）；垂直拖曳改音高或力度；橫向滑動塗抹。
KEYS顯示鍵盤，見下方 KEYS 模式。

track 條不支援長按。

樂句編輯器（TRACK 1 至 4）

樂句編輯器：最上為小節列（「1」與「+」），下方 START 1 END 16 STEPS 16，HIGH C5 / LOW C3，SEMI DOWN / UP，OCTAVE DOWN / UP，IMPORT MIDI，LOCK / CLEAR，COPY / PASTE（圖中 PASTE 灰顯），PHRASE FLIP，RATIO 1x，GLOBAL Minor 音階選單，VEL（選中）/ PROB / PITCH。音符格列為 C3 至 C5 的音階音，圖中有三個音符與播放位置線，最下為力度條。
小節列每頁 16 步，一頁一小節，最多 64 小節。點頁碼切換；長按 0.6 秒出現「DELETE BAR n?」Y / N。「+」新增小節。拖曳音符到邊緣停留 300 毫秒自動換頁。FOLLOW 按鈕使頁面跟隨播放。
START / END設定播放起訖小節，顯示「START n END m STEPS k」與 LENGTH。
HIGH / LOW音域上下限。點一下輸入音名，垂直拖曳每 24px 一個半音。
SEMI DOWN / UP整段移調 ±1 半音，到達極限時不可用。
OCTAVE DOWN / UP整段移調 ±12 半音，到達極限時不可用。
IMPORT MIDI匯入 .mid 檔。完成顯示「IMPORTED n NOTE(S)」，有略過時加「SKIPPED m」；錯誤以紅字顯示。訊息 4 秒後消失。
LOCK鎖定模式切換。
CLEAR兩段式：出現「CLEAR LOCK?」，Y 清除含鎖定的全部音符，N 只清除未鎖定音符。5 秒後自動取消。
COPY出現「COPY BAR n OR ALL?」，選 1 BAR 或 ALL。
PASTE可跨 track 貼上，貼上後剪貼簿保留。
PHRASE FLIP將播放視窗內的樂句倒轉，需至少 2 步。
RATIO15 個選項：x8、x6、x4、x3、x2.5、x2、x1.5、1x、/1.5、/2、/2.5、/3、/4、/6、/8。
SCALESegment 音階選單：GLOBAL、內建音階、使用者音階，各配 12 個根音。
VEL / PROB / PITCH切換底部 lane。VEL 顯示「VELOCITY n」（1 至 127）；PROB 顯示「PROB nn%」（0 至 100）；PITCH 顯示「PITCH nn%」，為隨機音高機率。

音符格手勢

  • 列為音域內的音階音；音符寬度為 gate，透明度為力度。
  • 音階外的音符顯示 2pt 警告框；鎖定音符顯示 4pt 框。
  • 點空格建立音符（力度 100、gate 0.5），建立後即為鎖定。點音符刪除，鎖定狀態保留。
  • 垂直拖曳超過 8pt 改音高；橫向拖曳改 gate（0.01 至 16）。最多 4 指同時操作。

手動輸入的音符預設鎖定，不受 LOCK 旋鈕與自動產生影響。只有 CLEAR 之後選 Y 才會清除鎖定音符。

DRUMS 編輯器（TRACK 5 至 8）

群組排列由上而下：TRACK 8 LEAD、7 TIMELINE、6 GROOVE、5 FOUNDATION。
聲部列TRACK 5：Kick、Low Tom；TRACK 6：Snare、Mid Tom、Clap；TRACK 7：HH Closed、HH Open；TRACK 8：High Tom、Crash。名稱隨 STYLE 變動。
分頁四軌共用小節分頁。
左側滑桿VARIATION、REST、GHOST、ACCENT、FILL，各 0 至 1，作用於目標軌。
目標軌2x2 格選 TRACK 5 至 8，彈窗標題 TARGET TRACK，至少保留一軌。
LOCK鎖定模式切換。
CLEAR先問 WHICH TRACK?（ALL / 8 / 7 / 6 / 5），再問 CLEAR LOCK? Y / N。
COPY / PASTE以四軌為一組複製貼上。
RATIO每軌獨立，顯示為 5 | 6 與 7 | 8 兩組。
VEL / PROB鼓軌只有這兩個 lane。
風格帶每群組一條，選 GLOBAL 或指定風格。可指定 MIDI Learn。

鼓格的手勢與旋律格相同。

KEYS 模式

KEYS 模式：上方 OCTAVE 的 - 與 + 按鈕與範圍 C3 至 C7，狀態文字 PLAYING，REST（灰顯）與 RECORD。下方兩排鍵盤，下排 C3 至 C4，上排 C5 至 C6，C 鍵有標示。
OCTAVE - / +移動鍵盤顯示的八度。
狀態STEP n/m、PLAYING、RECORDING、AUDITION。
REST步進錄音時輸入休止。
RECORD切換錄音。
鍵盤單音。鼓軌不可用，顯示提示文字。

5. VOICE

VOICE 全頁，圖中 TRACK 3 選 SAMPLE 音源並開啟 MULTI 模式。上方為標頭列與 8 個 TRACK 格，SEGMENT 列（1 為目前 segment）、DECAY 旋鈕（灰顯）、CLEAR（灰顯）與 SAVE。中段為檔案列：LOAD FOLDER、SLOT 01 C1、ONE SHOT、REVERSE、SLICE、MULTI（選中）、「- 16 +」。下方為 16 個 pad（左下為 C1）、PAGE 1 / 2 / 3、slot 參數旋鈕 LEVEL / PITCH / FILTER / 共振 / PAN、LOAD 與 CLEAR、波形區（NO SAMPLE）、LAUNCH 的 TRIGGER / GATE / LOOP / REVERSE、CHOKE OFF / A / B / C / D。

標頭與 track 格

標頭：SOUND SOURCE、EDITING TRACK 3、四個音源按鈕 SYNTH / SAMPLE（選中）/ PHYSICAL / AU。第二列為 TRACK 1 至 8 格，各顯示音源名稱與 M / S。第三列為 SEGMENT 1 至 8、DECAY、CLEAR、SAVE。
音源按鈕SYNTH、SAMPLE、PHYSICAL、AU，四選一。
TRACK 格顯示 track 名與音源。M 靜音；S 獨奏，長按 0.4 秒為排他獨奏。狀態與 MIXER 共用。切換 track 時，另一軌若在 RECORD 會停止。
SEGMENT 1 至 8選擇要編輯的 segment。有音色記憶的 segment 顯示圓點。
DECAY目前 track 的 DECAY，與 MAIN 相同。
CLEAR清除目前 segment 的音色記憶。
SAVE將目前面板參數（含和聲設定）存入 segment 記憶。

面板編輯規則：目前 segment 有記憶時，面板改的是記憶內容；沒有記憶時改的是 track 基底。取樣載入或錄音、PHYSICAL 的 MODEL 與 POLYPHONY、AU 載入都作用於 track 基底。SLICE 與 MULTI 為 track 層級設定，兩者互斥。編輯 segment 記憶時，面板顯示「EDITING SEGMENT n MEMORY」浮水印。

SYNTH

TRACK 1 至 5 為 wavetable 合成器，標題「OSCILLATOR WAVETABLE」，TRACK 5 標題「KICK VOICE WAVETABLE」。TRACK 6 至 8 為固定鼓合成器，面板顯示「BUILT-IN DRUM SYNTHESIZER WITH FIXED SOUNDS FOR THIS TRACK.」。

振盪器載波直接讀 wavetable 目前幀的波形取代正弦；未載入 wavetable 時為純正弦。
波形顯示顯示目前 wavetable 在 POSITION 位置的幀波形。POSITION 被 MOTION、MIDI 或 PERFORM 調變時顯示即時跟著換。
POSITION位於波形顯示右側。0 至 1，預設 0，幀之間線性內插；最左為第 0 幀（純正弦），向右進入檔案的幀。載波與調變器同時跟隨。TRACK 5 BYPASS 或無 wavetable 時停用。
BYPASS只有 TRACK 5，開啟時 FOLD、FEEDBACK、TONE、MODULATION 不作用，切窗點數選單鎖定。
PREVIOUS / NEXT切換上一個或下一個 wavetable。
名稱按鈕開啟「SELECT WAVETABLE」彈窗，含篩選欄與「NO WAVETABLE」項目。
CLEAR移除 wavetable，振盪器回到純正弦。
切窗點數256 / 512 / 1024 / 2048 / 4096，預設 2048。只改解碼時的切窗長度並重新取樣；單週期短於 2048 點的 wavetable 需改小點數以修正音高偏高。改變後該 track 的 wavetable 重新載入。

9. MOD ROUTE（長按調變）

MOD ROUTE 讓一個參數同時接收多個調變來源。優先順序：手指觸控最高，其次 MOTION 回放，最後 MOD ROUTE。停止播放時 MOD ROUTE 持續作用。

可長按的位置

  • PERFORM 畫布控件、側面板 MIXER 的 VOL 與送出格、側面板 SEQUENCER 的 LFO XY pad。
  • UTILITY 的 LFO 速度與 XY pad。
  • MIXER 的 DELAY / REVERB 旋鈕、粒子合成 pad 與各條。
  • VOICE 的取樣參數與 DECAY。
  • VISUAL 的參數條。

手勢：長按 0.6 秒，移動不超過 8pt，成功時有觸覺回饋。

12. MIDI Learn

進入與離開

  • 按 Transport 的 LEARN 或 Cmd+L 進入。可指定的控件顯示外框；XY pad 顯示四角。
  • 再按 LEARN 或 ESC 離開。

流程

  1. 點一個控件，進入等待狀態；SETUP 的 CURRENTLY LEARNING 顯示目標。
  2. 10 秒內送出 MIDI 訊息。點另一個控件會切換目標。
  3. 第一個符合的訊息完成綁定：按鈕為 MOMENTARY，其餘為連續值，曲線預設 LINEAR。既有綁定被取代。

訊息類型

可綁定CC、Note、Pitch Bend。
不可綁定Program Change。Aftertouch 與 SysEx 忽略。

綁定行為

MODELATCH 或 MOMENTARY。
TAKEOVERJUMP 直接跳到新值；PICKUP 在經過目前值後才接手。
SCALELINEAR、EXP、LOG。
MIN / MAX映射範圍。
分頁切換六個分頁各可綁定一個訊息。

綁定儲存於 midi_mappings.json，同時保留 .bak 備份。每個參數只能有一個綁定。
