1. 概要

HONKI は iPad 上で動作する 8 トラックのフレーズジェネレーターと音源システムです。1 つのパターンは 8 トラックで構成され、各トラックに 8 個のセグメントメモリスロットがあります。

トップバーの 6 つのページボタン：MAIN、VOICE、MIXER、UTILITY、PERFORM、VISUAL。図では MAIN が現在のページです。

トラック構成

TRACK 1 から 4メロディトラック。MAIN の TRACK 1 から 4 エディタでノートを編集します。
TRACK 5 から 8ドラムトラック。MIXER と PERFORM では FOUNDATION、GROOVE、TIMELINE、LEAD と表示されます。MAIN の DRUMS エディタで編集します。
役割のペアTRACK 1 と 5 が foundation、2 と 6 が groove、3 と 7 が timeline、4 と 8 が lead です。
セグメント各トラックに 8 個のセグメントスロットがあります。再生方式は SINGLE、SEQUENCER、RANDOM の 3 種類で、ドラムトラックには FOLLOW もあります。
音域の初期値MIDI ノート 36 から 72。
音源各トラックで SYNTH、SAMPLE、PHYSICAL、AU から 1 つを選択します。

6 つのページ

MAINフレーズ編集とセグメント管理。起動時の初期ページです。
VOICE音源の選択とパラメータ。
MIXER8 トラックのミキシング、EQ、コンプレッサー、エフェクトセンド、マスターエフェクト。
UTILITY8 ステージエンベロープ、LFO、CV 出力マトリクス。
PERFORMカスタムコントロールパネルとマッピング。
VISUAL映像ソースと 4 つの映像処理ステーション。

ページの切り替え：トップバーのページボタンをタップするか、外部キーボードの数字キー 1 から 6 を押します。編集オーバーレイが開いているときは、数字キーは TRACK 1 から 4 と DRUMS の切り替えになります。ページ切り替えは MIDI Learn に割り当てできます。2 本指スワイプによるページ切り替えは廃止されました。

ヘッダーの位置

トップバー右端の四角いボタンで、ヘッダーを置く角を切り替えます。順序は左上、右上、左下、右下です。ヘッダーが下側にあるとき、トランスポートバーは画面上部に移動します。

プロジェクトスロット

スロット数26 バンク（A から Z）、各バンクに 10 パターン（00 から 09）。スロット ID の形式は A-00 です。
スロットごとの保存内容バンク、programs、modulation、PERFORM レイアウト、MASTER FX、各トラックの AU。
アプリ全体で共通（スロットに依存しない）INPUT COMP、HUE、CV デバイスの割り当て。
起動時最後に使用したスロットを復元します。

Undo

Undo はバンク全体のスナップショットを単位とし、最大 100 ステップです。同一 tick 内の複数の変更は 1 ステップにまとめられ、ドラッグ操作も 1 ステップにまとめられます。MIDI Learn の書き込み、TAP テンポ、バンクの読み込みは undo に入りません。

2. トップバー

トップバー：左側にタイマー（図では 00:06）と「Click Twice to Reset」の案内、続いて MADZINE の文字、A-00 スロットメニュー、FILE メニュー、6 つのページボタン（MAIN が現在のページ）、右端にヘッダー位置ボタン。
タイマー起動時は「H O N K I」と表示されます。最初に PLAY を押して録音確認（Y または N）に答えると計測を開始します。形式は MM:SS です。ダブルタップでゼロに戻ります。横に「Click Twice to Reset」の案内が表示されます。
MADZINEブランド表示です。
A-00 メニュー2 階層のメニューです。第 1 階層の最上段が CLEAR、その下にバンク A から Z。第 2 階層がパターン 00 から 09 です。MIDI Learn で「次のバンク」を割り当てできます。
CLEARバンクに内容がある場合、先に「Clear everything?」と確認します。バンク、programs、SWING と TRANSPOSE のゼロ化、modulation、PERFORM レイアウト、MIDI 割り当て、各トラックの AU、MASTER FX、CV ルーティングを消去します。INPUT COMP、HUE、CV デバイスと STEREO OUT は保持されます。
FILE メニューCOPY、PASTE、SAVE、LOAD、および操作できない VERSION 項目（バージョン番号を表示）。PASTE はクリップボードが空でないときだけ使えます。
SAVE.honki ファイルを書き出します。iOS の初期ファイル名は「HONKI スロット ID」です。
LOAD.honki ファイルを読み込みます。「Replace current bank?」「Current changes will be lost.」と確認します。失敗時は「Bank File Error」と表示されます。
ページボタン6 つ。第 1 章を参照してください。
ヘッダー位置ボタン右端の四角いボタン。ヘッダーが現在ある角を表示します。タップするたびに順番に切り替わります。

.honki ファイル

現行のファイル形式には、バンク、programs、各トラックの AU、MASTER FX、modulation、PERFORM レイアウトが含まれます。旧バージョンの .honki ファイルとバンクのみのファイルも読み込めます。

3. トランスポート

録音停止ボタン録音状態のときだけ表示される赤い丸のカプセル型ボタンで、PLAY の左側にあります。押すと「STOP RECORDING?」Y / N が表示され、5 秒後に自動的に閉じます。停止後は 9 個の WAV ファイルが生成されます。第 14 章を参照してください。
MOTIONMOTION 記録状態を切り替えます。0.6 秒長押しで MOTION の記録をすべて削除します。MIDI Learn には割り当てできません。第 13 章を参照してください。
RESET再生中のみ使用でき、再生位置をゼロに戻します。MIDI Learn に割り当てできます。
BPM20 から 300。縦ドラッグで調整、タップで数値入力です。外部クロック使用時は 40% のグレー表示になります。MIDI Learn に割り当てできます。
TAP2 秒の窓内で最大 4 回のタップを平均します。最後のタップから 5 秒後にバッファを消去します。undo に入りません。外部クロック使用時は使えません。
SCALE2 階層のメニュー：第 1 階層がスケール、第 2 階層が 12 のルート音です。ボタンにはルート音とスケール名が表示されます。内蔵 16 種：Chromatic、Major、Minor、Penta Major、Penta Minor、Dorian、Phrygian、Lydian、Mixolydian、Locrian、Major Triad、Minor Triad、Blues、Arabic、Japanese、Whole Tone。その後にユーザースケールと USER SCALE EDITOR が並びます。メニューでは現在の STYLE に対する推奨度を星の数で示します。
SWING塗りつぶし型の横フェーダー、0 から 100。ダブルタップで 0.5 に戻ります。奇数ステップを stepDuration x 0.25 x swing だけ遅らせます。MIDI Learn に割り当てできます。
STYLEポップオーバー内に AMOUNT ノブ（0 から 1）と 9 種のスタイルが 2 列で並びます：West African、Afro-Cuban、Brazilian、Balkan、Indian、Gamelan、Electronic、Breakbeat、Techno。AMOUNT とスタイル番号はどちらも MIDI Learn に割り当てできます。
SETUPSETUP オーバーレイの開閉。第 11 章を参照してください。
LEARNMIDI Learn モードの切り替えです。表示は LEARN / LEARNING の間で切り替わります。ショートカットは Cmd+L です。割り当て可能なコントロールに 4pt の枠が表示されます。
UNDO / REDO戻せる内容がないときは 40% のグレー表示になります。ショートカットは Cmd+Z、Cmd+Shift+Z です。PERFORM レイアウトの編集は PERFORM 専用の undo スタックを使います。
HUE「HUE」の文字と色相リングです。ポップオーバーのタイトルは「ACCENT HUE」：外側のリングをドラッグで色相、中央の円盤を縦ドラッグで彩度（0 から 2）を変更します。

MAIN ページ全体。上部にトラックタブ列とパラメータ列。左カラムに MASTER TRANSPOSE、MASTER LOCK / DECAY / DENSITY ノブ、RANGE / PITCH / KEYS の切り替えと 8 本のトラックバー。右側に埋め込みのフレーズエディタ：小節列、START / END 列、HIGH C5 / LOW C3、SEMI と OCTAVE ボタン、IMPORT MIDI、LOCK / CLEAR、COPY / PASTE、PHRASE FLIP と RATIO 1x、GLOBAL Minor スケールメニュー、VEL / PROB / PITCH の切り替えとノートグリッド。

トラックタブ列

パラメータ列

パラメータ列：MUTE、SOLO、P（program メニュー）、LOCK / DECAY / DENSITY の 3 つのノブ、セグメント 1 から 8（図では 1 が現在のセグメント）、SINGLE / SEQUENCER / RANDOM の再生モード。

MASTER TRANSPOSE-、0、+ の 3 つのボタン。範囲は ±24 半音です。

RANGE各トラックバーの両端のハンドルをドラッグして、再生ウィンドウの開始点と終了点を設定します。

ノートグリッドのジェスチャー

  • 行は音域内のスケール音です。ノートの幅が gate、透明度がベロシティです。
  • スケール外のノートには 2pt の警告枠、ロックされたノートには 4pt の枠が表示されます。
  • 空のセルをタップするとノートを作成します（ベロシティ 100、gate 0.5）。作成したノートはロック状態になります。ノートをタップすると削除され、ロック状態は保持されます。
  • 8pt を超える縦ドラッグでピッチを変更、横ドラッグで gate（0.01 から 16）を変更します。最大 4 本指で同時に操作できます。

手動で入力したノートは初期状態でロックされ、LOCK ノブと自動生成の影響を受けません。ロックされたノートは CLEAR の後に Y を選んだときだけ消去されます。

5. VOICE

VOICE ページ全体。図では TRACK 3 が SAMPLE 音源を選択し、MULTI モードが有効です。上部にヘッダー列と 8 個の TRACK セル、SEGMENT 列（1 が現在のセグメント）、DECAY ノブ（グレー表示）、CLEAR（グレー表示）と SAVE。中段にファイル列：LOAD FOLDER、SLOT 01 C1、ONE SHOT、REVERSE、SLICE、MULTI（選択中）、「- 16 +」。下部に 16 個のパッド（左下が C1）、PAGE 1 / 2 / 3、スロットパラメータのノブ LEVEL / PITCH / FILTER / レゾナンス / PAN、LOAD と CLEAR、波形エリア（NO SAMPLE）、LAUNCH の TRIGGER / GATE / LOOP / REVERSE、CHOKE OFF / A / B / C / D。

SEGMENT 1 から 8編集するセグメントを選びます。音色メモリのあるセグメントには点が表示されます。
DECAY現在のトラックの DECAY で、MAIN と同じです。

9. MOD ROUTE（長押しモジュレーション）

MOD ROUTE は 1 つのパラメータに複数のモジュレーションソースを同時に受けさせます。優先順位は、指のタッチが最も高く、次に MOTION の再生、最後に MOD ROUTE です。再生を停止しても MOD ROUTE は作用し続けます。

長押しできる場所

  • PERFORM のキャンバスコントロール、サイドパネル MIXER の VOL とセンドセル、サイドパネル SEQUENCER の LFO XY パッド。
  • UTILITY の LFO レートと XY パッド。
  • MIXER の DELAY / REVERB ノブ、グラニュラー合成のパッドと各バー。
  • VOICE のサンプルパラメータと DECAY。
  • VISUAL のパラメータバー。

ジェスチャー：0.6 秒長押し、移動は 8pt 以内。成功時に触覚フィードバックがあります。

パネル

タイトルMOD ROUTE。XY パッドでは軸名が付きます。
ソースボタン16 個、4 行：OFF、SEQ、LFO 1 から 6、ENV 1 から 8。OFF ですべて消去します。
ボタンの動作選択済みで量が 0 でないソースをタップ：解除。選択済みで量が 0：+50% に設定。未選択で量が 0 でない：選択。未選択で量が 0：選択して +50% に設定。
AMOUNT-100 から +100%。タイトルに「ソース名 AMOUNT」、ソース未選択時は「SELECT A SOURCE」と表示されます。
CLEAR MOTION?そのパラメータに MOTION の記録があるとき、Y / N の行が表示されます。
閉じるパネルの外側をタップするか、Y / N に答えたときだけ閉じます。

ソース

SEQUTILITY エンベロープの出力、0 から 1。
LFO 1 から 6UNI / BI の設定に従い単極または双極です。
ENV 1 から 8各トラックのエンベロープ、0 から 1。そのトラックで現在選ばれている音源（SYNTH / SAMPLE / PHYSICAL / AU）のエンベロープを読みます。自分のトラックのパラメータも変調できます。UTILITY の OUTPUT マトリクスの入力にはありません。PERFORM コントロールでは ENV は使えず、ボタンはグレー表示です。

設定済みのパラメータの右上にソースマークが表示されます：m は MOTION、s は SEQ、1 から 6 は LFO、e1 から e8 は ENV です。ソースが多いときは「+」で省略されます。

MIDI Learn との関係

  • MIDI Learn モードが有効なとき、長押しで MOD ROUTE は開きません。
  • MIDI 割り当ては SETUP でのみ削除できます。再度 learn すると古い割り当てが置き換えられます。

12. MIDI Learn

開始と終了

  • トランスポートの LEARN または Cmd+L で開始します。割り当て可能なコントロールに枠が表示され、XY パッドは四隅が表示されます。
  • 再度 LEARN または ESC で終了します。

手順

  1. コントロールをタップして待機状態に入ります。SETUP の CURRENTLY LEARNING にターゲットが表示されます。
  2. 10 秒以内に MIDI メッセージを送ります。別のコントロールをタップするとターゲットが切り替わります。
  3. 最初に一致したメッセージで割り当てが完了します。ボタンは MOMENTARY、その他は連続値で、カーブの初期値は LINEAR です。既存の割り当ては置き換えられます。

メッセージの種類

割り当て可能CC、Note、Pitch Bend。
割り当て不可Program Change。Aftertouch と SysEx は無視されます。

割り当ての動作

MODELATCH または MOMENTARY です。
TAKEOVERJUMP は新しい値に直接移動し、PICKUP は現在の値を通過してから引き継ぎます。
SCALELINEAR、EXP、LOG。
MIN / MAXマッピング範囲です。
ページ切り替え6 つのページにそれぞれ 1 つのメッセージを割り当てできます。

割り当ては midi_mappings.json に保存され、同時に .bak バックアップが保持されます。各パラメータに持てる割り当ては 1 つだけです。
