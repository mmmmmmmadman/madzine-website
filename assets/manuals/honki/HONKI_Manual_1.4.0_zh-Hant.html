1. 總覽

HONKI 是 iPad 上的八軌樂句產生器與音源系統。一個 pattern 有 8 個 track，每個 track 各有 8 個 segment 記憶槽。

頂列的六個分頁按鈕：MAIN、VOICE、MIXER、UTILITY、PERFORM、VISUAL。圖中 MAIN 為目前分頁。

Track 結構

TRACK 1 至 4旋律軌。在 MAIN 的 TRACK 1 至 4 編輯器編輯音符。
TRACK 5 至 8鼓軌。在 MIXER 與 PERFORM 顯示為 FOUNDATION、GROOVE、TIMELINE、LEAD。在 MAIN 的 DRUMS 編輯器編輯。
角色配對TRACK 1 與 5 為 foundation，2 與 6 為 groove，3 與 7 為 timeline，4 與 8 為 lead。
Segment每個 track 有 8 個 segment 槽。播放方式有 SINGLE、SEQUENCER、RANDOM 三種，鼓軌另有 FOLLOW。
音域預設MIDI 音高 36 至 72。
音源每軌四選一：SYNTH、SAMPLE、PHYSICAL、AU。

六個分頁

MAIN樂句編輯與 segment 管理。啟動時的起始分頁。
VOICE音源選擇與參數。
MIXER八軌混音、EQ、壓縮、效果送出、主效果。
UTILITY8 段包絡、LFO、CV 輸出矩陣。
PERFORM自訂控制面板與對應。
VISUAL影像來源與四個影像處理站。

切換分頁：點頂列分頁按鈕，或用外接鍵盤數字鍵 1 至 6。編輯覆蓋層開啟時，數字鍵改為切換 TRACK 1 至 4 與 DRUMS。分頁切換可指定 MIDI Learn。雙指滑動切換分頁已移除。

標題位置

頂列最右的方形按鈕切換標題所在角落，順序為左上、右上、左下、右下。標題在下方時，Transport 列移到畫面上方。

專案槽

槽位數26 個 bank（A 至 Z），每個 bank 10 個 pattern（00 至 09）。槽位 ID 格式為 A-00。
每槽儲存內容bank、programs、modulation、PERFORM 版面、MASTER FX、各軌 AU。
全 app 共用（不隨槽位）INPUT COMP、HUE、CV 裝置綁定。
啟動時回復上次使用的槽位。

Undo

Undo 以整個 bank 的快照為單位，最多 100 步。同一 tick 內的多次修改合併為一步，拖曳過程合併為一步。MIDI Learn 寫入、TAP tempo、載入 bank 不進入 undo。

MADZINE品牌文字。

FILE 選單COPY、PASTE、SAVE、LOAD，以及不可點的 VERSION 項目（顯示版本號）。PASTE 只在剪貼簿非空時可用。
SAVE匯出 .honki 檔。iOS 預設檔名為「HONKI 槽位」。
LOAD匯入 .honki 檔。詢問「Replace current bank?」「Current changes will be lost.」。失敗時顯示「Bank File Error」。
分頁按鈕六個，見第 1 章。
角落按鈕右端方形按鈕，顯示目前標題角落。點一下依序輪換。

3. Transport

Transport 列由左至右：PLAY（圖中為停止狀態，顯示三角形圖示）、MOTION（兩行字，圖中為亮起的開啟狀態）、RESET、BPM 132、TAP、音階按鈕 E Mixolydian、SWING 53（灰顯）、STYLE 選單 TECHNO、SETUP、MIDI、MOD、上下排列的 UNDO 與 REDO，最右為 HUE 色圈。
PLAY / STOP未進入錄音狀態時按 PLAY，按鈕內出現 Y、REC?、N 三段，5 秒後自動收起。Y 為錄音並播放，N 為只播放。播放中按鈕顯示 STOP。可指定 MIDI Learn。
錄音停止按鈕只在錄音狀態顯示，為紅點膠囊按鈕，位於 PLAY 左側。按下出現「STOP RECORDING?」Y / N，5 秒後自動關閉。產生的檔案見第 14 章。
MOTION按鈕有兩行字：MOTION 與 HOLD RECORD。點一下切換 MOTION 回放：回放開啟時為黃色（預設），關閉時無色。按住 1 秒開始錄製，按住期間紅色由左向右填滿，提早放開或拖離即取消；錄製中按鈕為紅色，點一下停止錄製。開始錄製時回放自動開啟。不可指定 MIDI Learn。見第 13 章。
RESET只在播放中可用，將播放位置歸零。可指定 MIDI Learn。
BPM20 至 300。垂直拖曳調整，點一下輸入數字。使用外部時脈時灰顯 40%。可指定 MIDI Learn。
TAP2 秒視窗內最多 4 次點擊取平均。最後一次點擊 5 秒後清除緩衝。不進入 undo。外部時脈時不可用。
SCALE兩層選單：第一層音階，第二層 12 個根音。按鈕顯示根音與音階名。內建 16 種：Chromatic、Major、Minor、Penta Major、Penta Minor、Dorian、Phrygian、Lydian、Mixolydian、Locrian、Major Triad、Minor Triad、Blues、Arabic、Japanese、Whole Tone；之後列出使用者音階與 USER SCALE EDITOR。選單以星號數量標示目前 STYLE 的推薦程度。
SWING填滿式橫向 fader，0 至 100。點兩下回到 0.5。奇數步延後 stepDuration x 0.25 x swing。三連音音符不受 SWING 影響。可指定 MIDI Learn。
STYLE彈窗內有 AMOUNT 旋鈕（0 至 1）與 9 種風格，兩欄排列：West African、Afro-Cuban、Brazilian、Balkan、Indian、Gamelan、Electronic、Breakbeat、Techno。AMOUNT 與風格索引皆可指定 MIDI Learn。
SETUP開關 SETUP 面板。見第 11 章。
MIDI開關 MIDI Learn 模式。字樣固定為 MIDI，開啟時底色改變。快捷鍵 Cmd+L。開啟時可指定的控件出現虛線外框。按下 MIDI 會關閉 MOD。見第 12 章。
MOD開關 MOD 模式，位於 MIDI 右側。啟動時為關閉。開啟時按鈕為強調色，可調變的控件出現實線強調色外框；點有外框的控件不會改值，而是開啟 MOD ROUTE 面板。沒有外框的控件照常操作。與 MIDI 互斥。不可指定 MIDI Learn。見第 9 章。
UNDO / REDO無可復原內容時灰顯 40%。快捷鍵 Cmd+Z、Cmd+Shift+Z。PERFORM 版面編輯使用 PERFORM 自己的 undo 堆疊。
HUE「HUE」文字與色圈。彈窗標題「ACCENT HUE」：外環拖曳改色相，中央圓盤垂直拖曳改飽和度（0 至 2）。

USER SCALE EDITOR

CLOSE關閉編輯表單。
SCALE NAME音階名稱輸入欄。
音級按鈕12 個，2 列 6 欄，相對於全域 ROOT。預設包含根音。
音程摘要顯示已選音程；未選任何音級時顯示「SELECT AT LEAST ONE PITCH CLASS」。

4. MAIN

MAIN 全頁。上方為 track 分頁列與參數列；左欄為 MASTER TRANSPOSE、MASTER LOCK / DECAY / DENSITY 旋鈕、KEYS 鈕與 8 條 track 條；右側為嵌入的樂句編輯器，含小節列、START / END 列、左側按鈕欄（最上為 TRI 與 RANGE，最下為音階選單與 lane 下拉選單）與音符格。

Track 分頁列

Track 分頁列：兩端各一個斜向箭頭全螢幕按鈕，MULTI、S、提示文字（長按靜音、點兩下獨奏），以及 1-1 至 8-1 八個 track 分頁（圖中 1-1 為目前 track），每個分頁上方有色點。
全螢幕按鈕列兩端各一個斜向箭頭按鈕，開啟或關閉編輯器全螢幕。
MULTI多軌同步編輯。開啟時，被同步的旋鈕顯示虛線環。
S清除所有 track 的 solo。
Track 分頁點一下選擇 track；0.35 秒內點兩下切換 SOLO；長按 0.45 秒切換 MUTE。分頁文字為 track 編號與目前 segment（例如 1-1）。

參數列

參數列：MUTE、SOLO、P（program 選單）、LOCK / DECAY / DENSITY 三個旋鈕、segment 1 至 8（圖中 1 為目前 segment）、SINGLE / SEQUENCER / RANDOM 播放模式。
MUTE / SOLO目前 track 的靜音與獨奏。
PProgram 選單：SAVE、LOAD、CLEAR，對象為 Program 1 至 8。
LOCK0 至 100%，垂直拖曳，無點兩下重設。
DECAY旋律軌顯示為 0 至 100%，內部範圍 -0.99 至 0.99；鼓軌範圍 0.2 至 2.0（1.0 顯示為 44%）。點兩下重設（鼓軌 1.0，旋律軌 -0.78）。
DENSITY0 至 100%。點兩下清除 segment 的覆寫值。
Segment 1 至 8三種狀態：無、空、有內容。有 RATIO 時顯示標籤。鏈狀態顯示在底部 3pt 條，播放中在頂部顯示 3pt 線。點擊優先順序：鏈設定中 > RANDOM 池 > MULTI > 選擇。
SINGLE只播放目前 segment，顯示 SEG n。
SEQUENCER依序點 START、起點槽、END、終點槽，之後顯示 SEQ a-b。
RANDOM顯示 CHOOSE，點槽位加入或移出隨機池。
FOLLOW鼓軌專用，跟隨配對旋律軌的 segment。

左欄

左欄：MASTER TRANSPOSE，MASTER LOCK / DECAY / DENSITY 旋鈕，右上為 KEYS 鈕，之後是 8 條 track 條（標示 1 至 8 與 SEG 1），每條上方有步數刻度與音符名稱。圖中 track 1 有外框表示為目前 track。
MASTER TRANSPOSE由左至右為「-」、數值欄、「+」。數值欄點一下輸入數字，垂直拖曳改值。範圍 ±24 半音。
MASTER LOCK / DECAY / DENSITY同時寫入全部 8 軌的對應參數。
KEYS標題列右側唯一的按鈕。開啟時 track 條換成鍵盤，見下方 KEYS 模式。
track 條顯示該軌目前小節的內容。鼓軌的柱高為力度；旋律軌的柱高為音高位置，濃淡為力度。播放範圍外的格子變暗。步數刻度為目前小節的步數編號，頁面與右側編輯器同步。track 條只供檢視，音符在右側編輯器輸入。
範圍把手每條 track 條兩端的把手常駐，拖曳設定播放視窗的起點與終點，拖曳時該軌顯示起訖步數。把手拖到邊緣停留會翻頁。最多 4 指同時拖曳。
三連音記號該段有三連音音符時，track 條每兩格底部出現一條細的三等分記號。第一等分與直拍共用，不另外畫；第二、第三等分有音符時填上軌色，濃淡表示力度。

track 條不支援長按。

樂句編輯器（TRACK 1 至 4）

樂句編輯器：最上為小節列（「1」與「+」），下方 START 1 END 16 STEPS 16，左側按鈕欄由上而下為 TRI / RANGE、SEMI DOWN / SEMI UP、OCTAVE DOWN / OCTAVE UP、IMPORT MIDI、LOCK / CLEAR、COPY / PASTE、PHRASE FLIP / RATIO、音階選單，最下一列左半為 lane 下拉選單（圖中為 VELOCITY）、右半為 EDIT；右側為音符格，最下為力度條。

左側按鈕欄由上而下：FOLLOW（有多個小節時才出現）、TRI 與 RANGE、SEMI DOWN 與 SEMI UP、OCTAVE DOWN 與 OCTAVE UP、IMPORT MIDI、LOCK 與 CLEAR、COPY 與 PASTE、PHRASE FLIP 與 RATIO、SCALE 選單，最下一列為 lane 下拉選單與 EDIT。

小節列一頁一小節 16 步，最多 64 小節。點頁碼切換；長按 0.6 秒出現「DELETE BAR n?」Y / N。「+」新增小節。超過 8 小節時每次顯示 8 個，兩端有切換鈕；全螢幕顯示全部小節。播放中的小節底部有色帶。
全螢幕全螢幕時一次顯示兩小節，邊緣翻頁一次翻兩小節。頁碼、1 BAR 的 COPY / PASTE 與刪小節仍以單一小節為單位。
邊緣翻頁橫向拖長音符、在 lane 上橫掃、拖曳 START / END 時，到邊緣停留 0.3 秒自動翻頁。垂直改音高不翻頁。
START / END設定播放起訖步，顯示「START n END m STEPS k」；超過 16 步時加上 BARS，RATIO 不是 1x 時加上 RATE。
FOLLOW使頁面跟隨播放。只由此鈕切換。
TRI開關三連音格線，見下方「TRI 三連音格線」。
RANGE開啟 PITCH RANGE 視窗，內有 HIGH 與 LOW 兩欄，為音域上下限。點一下輸入音名，垂直拖曳每 24px 一個半音，兩欄可同時拖曳。HIGH 至少比 LOW 高一個半音。點視窗外關閉。
SEMI DOWN / UP整段移調 ±1 半音，到達極限時不可用。三連音音符一起移調。
OCTAVE DOWN / UP整段移調 ±12 半音，到達極限時不可用。三連音音符一起移調。
IMPORT MIDI匯入 .mid 檔。完成顯示「IMPORTED n NOTE(S)」，有略過時加「SKIPPED m」；錯誤以紅字顯示。訊息 4 秒後消失。不影響三連音音符。
LOCK鎖定模式切換。
CLEAR兩段式：出現「CLEAR LOCK?」，Y 清除含鎖定的全部音符，N 只清除未鎖定音符，三連音音符同樣處理。5 秒後自動取消。
COPY出現「COPY BAR n OR ALL?」，選 1 BAR 或 ALL。三連音音符一起複製。
PASTE可跨 track 貼上，貼上後剪貼簿保留。來源沒有三連音時，目標的三連音會被清除。
PHRASE FLIP將播放視窗內的樂句倒轉，需至少 2 步。三連音音符一起倒轉。
RATIO鈕面顯示 RATIO 與目前值。15 個選項：x8、x6、x4、x3、x2.5、x2、x1.5、1x、/1.5、/2、/2.5、/3、/4、/6、/8。三連音跟著等比縮放。
SCALESegment 音階選單：GLOBAL、內建音階、使用者音階，各配 12 個根音。
lane 下拉選單位於按鈕欄最下面一列的左半格，選擇音符格下方的 lane，共七項，見下表。
EDIT位於同一列的右半格，緊鄰 lane 下拉選單，用來展開加高的參數編輯區，見下方「EDIT 參數編輯區」。
點 RANGE 開啟的 PITCH RANGE 視窗，HIGH 為 C5、LOW 為 C3。

lane

VELOCITY1 至 127，拖曳時顯示「VELOCITY n」。新音符為 100。
PROBABILITY0 至 100%，顯示「PROB nn%」。預設 100%。
PITCH PROBABILITY0 至 100%，顯示「PITCH nn%」，為隨機音高機率。預設 0。
DECAY0 至 100%，顯示「DECAY nn%」。預設 50%，即沿用該 segment 的 DECAY；低於 50% 較短，高於 50% 較長。
RATCHET0 至 100%，顯示「RATCHET nn%」，為該步發生重複觸發的機率。預設 0。
RATCHET COUNT重複觸發的次數，九檔：2、3、4、6、8、12、16、24、32，顯示「COUNT n」。預設 2。RATCHET 為 0 的音符，此 lane 的柱變淡，仍可編輯。
RATCHET COUNT PROBABILITY0 至 100%，顯示「COUNT PROB nn%」。預設 0。RATCHET 發生時再判定一次：成立時次數改為隨機，由 1 與不超過所設 COUNT 的各檔中抽出，抽到 1 表示該步不重複觸發；不成立時依所設 COUNT。

所有 lane 都支援垂直拖曳與單指橫掃。鎖定音符的 DECAY 與 RATCHET 值不會被自動產生改掉。

lane 下拉選單展開，由上而下為 VELOCITY、PROBABILITY、PITCH PROBABILITY、DECAY、RATCHET、RATCHET COUNT、RATCHET COUNT PROBABILITY 七項。
lane 選為 RATCHET COUNT：音符格下方的柱為各步的重複觸發次數，RATCHET 為 0 的步柱色較淡。

EDIT 參數編輯區

左側按鈕欄最下面一列分成兩半：左半是 lane 下拉選單，右半是 EDIT 按鈕，1 至 8 軌都有。按下 EDIT 展開加高的參數編輯區：上方的音符格收成一半高度，下半空間改放編輯區。再按一次收回，音符格回到原本的高度。EDIT 展開時 lane 下拉選單仍可使用，編輯區跟著目前選定的參數走。

左側按鈕欄最下面一列：左半為 lane 下拉選單，名稱過長時縮寫；右半為 EDIT 按鈕。

TRACK 1 至 4 的編輯區就是原本的 lane，只是加高，手勢不變，一樣是垂直拖曳與單指橫掃。編輯區頂端多一列，以該參數的顏色顯示參數全名；這一列只是標示，不吃觸控。下拉選單縮成半格後字樣可能縮寫，這一列一律寫出完整名稱。

TRACK 1 按下 EDIT：上方音符格收成一半高度，下方為加高的參數編輯區，頂端一列以該參數的顏色顯示參數全名。

TRI 三連音格線

  • TRI 只切換顯示與編輯用的格線。直拍音符與三連音音符是兩份資料，不論 TRI 開或關，兩者都會播放。
  • 旋律軌的 TRI 只作用於目前這一軌，各軌分開記。TRI 的開關狀態不存檔，重開 app 後為關閉。
  • TRI 開啟時，一小節由 16 欄變為 24 欄：每兩個直拍步分成三格。每組第一格與直拍的偶數步是同一個音符。

旋鈕的 MAPPING 面板：左側 8 個 slot（圖中 slot 1 為 MASTER FILTER）與 CLEAR SLOT、REVERSE RANGE，右側為 TARGET 的分類與參數，最下為範圍條。
XY PAD 的 MAPPING 面板：上方選 TWO AXIS 或 FOUR WAY，左側為 UP / DOWN / LEFT / RIGHT 四個方向與其指派，另有 SPRING TO CENTER、CLEAR DIRECTION 與 REVERSE RANGE。

9. MOD ROUTE

MOD ROUTE 讓一個參數同時接收多個調變來源。手指在控件上時，手動值取代 MOTION 回放；MOD ROUTE 持續作用，並與 MOTION 相加。停止播放時 MOD ROUTE 持續作用。

開啟方式

  • 按 Transport 的 MOD 進入 MOD 模式。可調變的控件出現實線強調色外框。
  • 點有外框的控件，開啟該參數的 MOD ROUTE 面板，有觸覺回饋。此時控件的值不會改變。
  • 再按一次 MOD 離開。MOD 模式與 MIDI Learn 模式互斥；每次啟動 app 時 MOD 為關閉。

舊版的長按開啟方式已移除。

Transport 的 MOD 開啟時的 MIXER 頁：可調變的控件出現外框。

可調變的位置

  • MAIN 參數列的 DECAY。
  • VOICE 的音源參數，以及取樣的起點、終點與 GRAIN SHAPE。
  • MIXER 每軌：DELAY、REVERB、FX CHAIN 送出、旁鏈量、PAN、MIX、LEVEL，以及 A1 至 A3 的送出量。FILTER、LOCK、DENSITY、M、S 與 MIXER 頁的 DECAY 不支援。
  • MIXER 的 EFFECT 列：DELAY 的 LEFT、RIGHT、FEEDBACK、LEVEL；REVERB 的 SIZE、DAMP、DECAY、LEVEL；FX CHAIN 的 RETURN、各位置的參數與 DRY WET。
  • UTILITY 的 LFO 速度與 XY pad。
  • PERFORM 畫布的全部控件；側面板 EFFECT 與 FX CHAIN 的各橫桿、UTILITY 分頁的 LFO SPEED。側面板 MIXER 的 VOL 不支援。
  • VISUAL 的 MIX 與參數條。
