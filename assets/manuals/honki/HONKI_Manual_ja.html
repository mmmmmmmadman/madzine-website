1. 概要

HONKI は iPad と Mac で動作する 8 トラックのフレーズジェネレーターと音源システムです。Mac 版には Apple シリコンと macOS 14 以降が必要です。このマニュアルは iPad 版を基準に説明しています。Mac 版で異なる点は各章に記載しています。1 つのパターンは 8 トラックで構成され、各トラックに 8 個のセグメントメモリスロットがあります。

トップバーの 6 つのページボタン：MAIN、VOICE、MIXER、UTILITY、PERFORM、VISUAL。図では MAIN が現在のページです。

トラック構成

TRACK 1 から 4メロディトラック。MAIN の TRACK 1 から 4 エディタでノートを編集します。
TRACK 5 から 8ドラムトラック。MIXER と PERFORM では FOUNDATION、GROOVE、TIMELINE、LEAD と表示されます。MAIN の DRUMS エディタで編集します。
役割のペアTRACK 1 と 5 が foundation、2 と 6 が groove、3 と 7 が timeline、4 と 8 が lead です。
セグメント各トラックに 8 個のセグメントスロットがあります。再生方式は SINGLE、SEQUENCER、RANDOM の 3 種類で、ドラムトラックには FOLLOW もあります。
音域の初期値MIDI ノート 36 から 72。
音源各トラックで SYNTH、SAMPLE、PHYSICAL、AU から 1 つを選択します。

6 つのページ

MAINフレーズ編集とセグメント管理。起動時の初期ページです。
VOICE音源の選択とパラメータ。
MIXER8 トラックのミキシング、EQ、コンプレッサー、エフェクトセンド、マスターエフェクト。
UTILITY8 ステージエンベロープ、LFO、CV 出力マトリクス。
PERFORMカスタムコントロールパネルとマッピング。
VISUAL映像ソースと 4 つの映像処理ステーション。

ページの切り替え：トップバーのページボタンをタップするか、外部キーボードの数字キー 1 から 6 を押します。編集オーバーレイが開いているときは、数字キーは TRACK 1 から 4 と DRUMS の切り替えになります。ページ切り替えは MIDI Learn に割り当てできます。2 本指スワイプによるページ切り替えは廃止されました。

ヘッダーの位置

トップバー右端の四角いボタンで、ヘッダーを置く角を切り替えます。順序は左上、右上、左下、右下です。ヘッダーが下側にあるとき、トランスポートバーは画面上部に移動します。

プロジェクトスロット

スロット数26 バンク（A から Z）、各バンクに 10 パターン（00 から 09）。スロット ID の形式は A-00 です。
スロットごとの保存内容バンク、programs、modulation、PERFORM レイアウト、MASTER FX、各トラックの AU、MIXER のバス選択。MIDI の割り当てと KEYBOARD の割り当ては 1.4.13 からアプリ全体で共通になり、スロットごとには保存されません。
アプリ全体で共通（スロットに依存しない）INPUT COMP、HUE、CV デバイスの割り当て、EXTERNAL INPUT のルーティング、MIDI 入力デバイスのチェック、MIDI の割り当て、KEYBOARD の割り当て、SETUP の TRACK ORDER、VISUAL のオン / オフ。SETTINGS 系の設定（CLOCK IN、ENV DELAY、RECORDING TRACKS、GENERATE VELOCITY、MOD OUTPUT のチャンネル）は、スロットの切り替え、ファイルの読み込み、CLEAR、UNDO のいずれでも保持されます。
起動時最後に使用したスロットを復元します。
旧バージョンからの更新MIDI の割り当てがアプリ全体で共通になった後の初回起動時に、起動時のスロットの割り当てが 1 回だけコピーされ、共通の割り当てになります。

Undo

Undo はバンク全体のスナップショットを単位とし、最大 100 ステップです。同一 tick 内の複数の変更は 1 ステップにまとめられ、ドラッグ操作も 1 ステップにまとめられます。MIDI Learn の書き込み、TAP テンポ、バンクの読み込みは undo に入りません。

.honki ファイル

現行のファイル形式には、バンク、programs、各トラックの AU、MASTER FX、modulation、PERFORM レイアウト、MIDI の割り当てが含まれます。SAVE で書き出すときは MIDI の割り当ても含まれますが、LOAD ではファイル内の MIDI の割り当ては無視され、現在の割り当てはそのまま残ります。旧バージョンの .honki ファイルとバンクのみのファイルも読み込めます。

3. トランスポート

トランスポート列、左から順に：PLAY（図は停止中で三角のアイコン）、MOTION（2 行表示、図ではオンで点灯）、RESET、BPM 132、TAP、スケールボタン E Mixolydian、SWING 53（グレー表示）、STYLE メニュー TECHNO、SETUP、MIDI、MOD、上下に並んだ UNDO と REDO、右端に HUE のカラーホイール。
PLAY / STOP録音状態でないときに PLAY を押すと、ボタン内に Y、REC?、N の 3 つが表示され、5 秒後に自動で閉じます。Y は録音して再生、N は再生のみです。再生中はボタンに STOP と表示されます。MIDI Learn に割り当てできます。Y を選ぶと先にストレージの空き容量を確認します。第 14 章を参照してください。
録音停止ボタン録音状態のときだけ表示される赤い点のカプセル型ボタンで、PLAY の左にあります。押すと「STOP RECORDING?」Y / N が表示され、5 秒後に自動で閉じます。生成されるファイルは第 14 章を参照してください。
MOTIONボタンには MOTION と HOLD RECORD の 2 行が表示されます。タップで MOTION の再生を切り替えます。再生オンのときは黄色（初期状態）、オフのときは無色です。1 秒押し続けると録音を開始します。押している間は赤が左から右へ満ちていき、早く離すかボタンの外へドラッグすると取り消されます。録音中はボタンが赤になり、タップで録音を停止します。録音を開始すると再生は自動でオンになります。MIDI Learn には割り当てできません。第 13 章を参照してください。
RESET再生中のみ使用でき、再生位置を先頭に戻します。MIDI Learn に割り当てできます。
BPMノブで、20 から 300。上下にドラッグして調整します。ダブルタップでのリセットや、タップでの数値入力はありません。0.6 秒長押しすると MASTER CLOCK ポップオーバーが開き、PROBABILITY フェーダー（ダブルタップで 100%）があります。100% 未満ではステップのトリガーを確率でスキップし、再生位置はそのまま進みます。クロック出力は影響を受けません。PROBABILITY は MIDI Learn、PERFORM、KEYBOARD に割り当てできます。外部クロック使用時はグレー表示になり、受信中のテンポを表示します。プロジェクトの BPM は書き換えられず、クロックソースを INT に戻すと元の値に戻ります。BPM は MIDI Learn に割り当てできます。
TAP2 秒の範囲内で最大 4 回のタップを平均します。最後のタップから 5 秒後にバッファを消去します。undo の対象外です。外部クロック使用時は使用できません。
SCALE2 階層のメニューです。1 階層目がスケール、2 階層目が 12 のルート音です。ボタンにはルート音とスケール名が表示されます。内蔵 16 種類：Chromatic、Major、Minor、Penta Major、Penta Minor、Dorian、Phrygian、Lydian、Mixolydian、Locrian、Major Triad、Minor Triad、Blues、Arabic、Japanese、Whole Tone。その後にユーザースケールと USER SCALE EDITOR が並びます。メニューではアスタリスクの数で現在の STYLE への適合度を示します。
SWING塗りつぶし式の横フェーダー、0 から 100。ダブルタップで 0.5 に戻ります。奇数ステップを stepDuration x 0.25 x swing だけ遅らせます。3 連符のノートは SWING の影響を受けません。MIDI Learn に割り当てできます。
STYLEポップオーバー内に AMOUNT ノブ（0 から 1）と 9 種類のスタイルが 2 列で並びます：West African、Afro-Cuban、Brazilian、Balkan、Indian、Gamelan、Electronic、Breakbeat、Techno。AMOUNT とスタイル番号はどちらも MIDI Learn に割り当てできます。
SETUPSETUP パネルを開閉します。第 11 章を参照してください。
MIDIMIDI Learn モードを切り替えます。表示は常に MIDI で、オンのときは背景色が変わります。ショートカットは Cmd+L。オンのとき、割り当てできるコントロールに破線の枠が表示されます。MIDI を押すと MOD はオフになります。第 12 章を参照してください。
MODMOD モードを切り替えます。MIDI の右にあります。起動時はオフです。オンのときはボタンがアクセントカラーになり、モジュレーションできるコントロールに実線のアクセントカラーの枠が表示されます。枠のあるコントロールをタップしても値は変わらず、MOD ROUTE パネルが開きます。枠のないコントロールは通常どおり操作できます。MIDI とは同時にオンにできません。MIDI Learn には割り当てできません。第 9 章を参照してください。
UNDO / REDO取り消す内容がないときは 40% のグレー表示になります。ショートカットは Cmd+Z、Cmd+Shift+Z。PERFORM のレイアウト編集は PERFORM 専用の undo スタックを使います。
HUE「HUE」の文字とカラーホイール。ポップオーバーのタイトルは「ACCENT HUE」で、外側のリングをドラッグして色相を、中央の円を縦ドラッグして彩度（0 から 2）を変更します。

4. MAIN

MAIN ページ全体。上部にトラックタブ列とパラメータ列、左カラムに MASTER TRANSPOSE、MASTER LOCK / DECAY / DENSITY ノブ、KEYS ボタンと 8 本のトラックバー、右側に埋め込みのフレーズエディタ（小節列、START / END 列、左のボタン列（最上部が TRI と RANGE、最下部がスケールメニューとレーンのドロップダウン）、ノートグリッド）があります。

トラックタブ列

トラックタブ列：両端に斜め矢印の全画面ボタン、MULTI、S、案内文（長押しでミュート、ダブルタップでソロ）、1-1 から 8-1 の 8 個のトラックタブ（図では 1-1 が現在のトラック）。各タブの上に色付きの点があります。
全画面ボタン列の両端にある斜め矢印のボタンで、エディタの全画面表示を開閉します。
MULTI複数トラックの同期編集です。有効時、同期中のノブには破線のリングが表示されます。GLOBAL グループの MULTI を PERFORM、MIDI、KEYBOARD に割り当てできます。MAIN ページを表示しているときだけ働きます。
S全トラックのソロを解除します。対応する割り当て先は GLOBAL グループの UN-SOLO ALL です。
トラックタブタップでトラックを選択。0.35 秒以内のダブルタップで SOLO 切り替え、0.45 秒の長押しで MUTE 切り替えです。タブの表示はトラック番号と現在のセグメント（例：1-1）です。

パラメータ列

パラメータ列：MUTE、SOLO、P（program メニュー）、LOCK / DECAY / DENSITY の 3 つのノブ、セグメント 1 から 8（図では 1 が現在のセグメント）、SINGLE / SEQUENCER / RANDOM の再生モード。
MUTE / SOLO現在のトラックのミュートとソロです。
PProgram メニュー：SAVE、LOAD、CLEAR。対象は Program 1 から 8 です。
LOCK0 から 100%。縦ドラッグです。ダブルタップによるリセットはありません。
DECAYディケイの時間倍率で、全トラック 0.2 から 2.0（1.0 が 44% と表示）です。上げるとディケイが長くなり、メロディトラックではテールが音符の長さを超えて、同じトラックの次の音が鳴るまで伸びます。ダブルタップで 1.0 にリセットします。
DENSITY0 から 100%。ダブルタップでセグメントの上書き値を消去します。
セグメント 1 から 83 つの状態：なし、空、内容あり。RATIO があるときはラベルを表示します。チェーン状態は下端の 3pt バー、再生中は上端の 3pt ラインで示します。タップの優先順位：チェーン設定中、RANDOM プール、MULTI、選択の順です。
<< / >>8 つのセグメントスロットの左右に 1 つずつあります。現在のトラックの前または次の保存済み Program（1 から 8）を読み込みます。空のものは飛ばし、端で折り返しません。読み込めるものがないときはグレー表示で無効になります。まだ Program を読み込んでいないときは、>> は Program 1 から、<< は Program 8 から探します。長押しで MIDI Learn でき、PERFORM と KEYBOARD の割り当て先は PREVIOUS PROGRAM / NEXT PROGRAM です。
SINGLE現在のセグメントだけを再生します。表示は SEG n です。
SEQUENCERSTART、開始スロット、END、終了スロットの順にタップすると、SEQ a-b と表示されます。
RANDOMCHOOSE と表示され、スロットをタップしてランダムプールに追加または除外します。
FOLLOWドラムトラック専用。ペアになったメロディトラックのセグメントに追従します。

左カラム

左カラム：MASTER TRANSPOSE、MASTER LOCK / DECAY / DENSITY ノブ、右上に KEYS ボタン、続いて 8 本のトラックバー（1 から 8 と SEG 1 の表示）。各バーの上にステップ目盛りとノート名があります。図では track 1 に枠があり現在のトラックを示します。
MASTER TRANSPOSE左から「-」、数値欄、「+」です。数値欄はタップで数値を入力、縦ドラッグで値を変更します。範囲は ±24 半音です。
MASTER LOCK / DECAY / DENSITY8 トラックすべての対応するパラメータに同時に書き込みます。
KEYS見出し行の右にある唯一のボタンです。オンにするとトラックバーが鍵盤に切り替わります。下の KEYS モードを参照してください。
トラックバーそのトラックの現在の小節の内容を表示します。ドラムトラックは柱の高さがベロシティ、メロディトラックは柱の高さが音高の位置、濃淡がベロシティです。再生範囲外のマスは暗くなります。ステップ目盛りは現在の小節のステップ番号で、ページは右のエディタと連動します。トラックバーは表示専用で、ノートは右のエディタで入力します。
範囲ハンドル各トラックバーの両端のハンドルは常に表示されます。ドラッグして再生ウィンドウの始点と終点を設定し、ドラッグ中はそのトラックの開始と終了のステップが表示されます。ハンドルを端で止めるとページが切り替わります。最大 4 本指で同時にドラッグできます。
3 連符マーカーそのセグメントに 3 連符のノートがあるとき、トラックバーの 2 マスごとの下部に細い 3 等分のマーカーが表示されます。1 つ目はストレートのステップと共通のため別には描かれません。2 つ目と 3 つ目にノートがあるとトラックの色で塗られ、濃淡がベロシティを示します。

トラックバーは長押しに対応していません。

フレーズエディタ（TRACK 1 から 4）

フレーズエディタ：最上部に小節列（「1」と「+」）、その下に START 1 END 16 STEPS 16。左のボタン列は上から TRI / RANGE、SEMI DOWN / SEMI UP、OCTAVE DOWN / OCTAVE UP、IMPORT MIDI、LOCK / CLEAR、COPY / PASTE、PHRASE FLIP / RATIO、スケールメニュー、最下段は左半分がレーンのドロップダウン（図では VELOCITY）、右半分が EDIT。右側がノートグリッドで、最下部はベロシティバーです。

左のボタン列は上から順に：DELAY フェーダーと SYNC（TRACK DELAY）、FOLLOW（小節が複数あるときのみ表示）、TRI と RANGE、SEMI DOWN と SEMI UP、OCTAVE DOWN と OCTAVE UP、IMPORT MIDI、LOCK と CLEAR、COPY と PASTE、PHRASE FLIP と RATIO、SCALE メニュー、最下段のレーンのドロップダウンと EDIT。

小節列1 ページが 1 小節 16 ステップで、最大 64 小節です。ページ番号をタップして切り替えます。0.6 秒長押しすると「DELETE BAR n?」Y / N が表示されます。「+」で小節を追加します。8 小節を超えると 8 個ずつ表示され、両端に切り替えボタンが付きます。全画面ではすべての小節が表示されます。再生中の小節は下部に色の帯が付きます。
全画面全画面では 2 小節を同時に表示し、端でのページ送りは 2 小節ずつになります。ページ番号、1 BAR の COPY / PASTE、小節の削除は 1 小節単位のままです。
端でのページ送りノートを横に伸ばすとき、レーンを横になぞるとき、START / END をドラッグするときに、端で 0.3 秒止めると自動でページが切り替わります。縦の音高変更ではページは切り替わりません。

ノートグリッドのジェスチャー

  • 行は音域内のスケール音です。ノートの幅がゲート、透明度がベロシティです。

9. MOD ROUTE

MOD ROUTE は、1 つのパラメータに複数のモジュレーションソースを同時に受けさせます。指がコントロール上にある間は手動の値が MOTION の再生に置き換わります。MOD ROUTE は作用し続け、MOTION に加算されます。再生を停止しても MOD ROUTE は作用し続けます。

開き方

  • トランスポートの MOD を押して MOD モードに入ります。モジュレーションできるコントロールに実線のアクセントカラーの枠が表示されます。
  • 枠のあるコントロールをタップすると、そのパラメータの MOD ROUTE パネルが開き、触覚フィードバックがあります。このときコントロールの値は変わりません。
  • もう一度 MOD を押すと終了します。MOD モードと MIDI Learn モードは同時にオンにできません。アプリの起動時は毎回 MOD はオフです。

旧バージョンの長押しで開く方法は廃止されました。

トランスポートの MOD をオンにした MIXER ページ。モジュレーションできるコントロールに枠が付く。

モジュレーションできる場所

  • MAIN パラメータ列の DECAY。
  • VOICE の音源パラメータ、およびサンプルの開始点、終了点、GRAIN SHAPE。
  • MIXER の各トラック：DELAY、REVERB、FX CHAIN のセンド、サイドチェイン量、PAN、MIX、LEVEL、および A1 から A3 の送り量。FILTER、LOCK、DENSITY、M、S、MIXER ページの DECAY は対応していません。
  • MIXER の EFFECT 列：DELAY の LEFT、RIGHT、FEEDBACK、LEVEL。REVERB の SIZE、DAMP、DECAY、LEVEL。FX CHAIN の RETURN、各ポジションのパラメータと DRY WET。
  • UTILITY の LFO スピード、WAVEFORM、SHAPE。
  • フレーズエディタの TRACK DELAY。
  • PERFORM キャンバスのすべてのコントロールと、サイドパネルの EFFECT と FX CHAIN の各横バー。サイドパネルの GRID ページは対応していません。
  • VISUAL の MIX とパラメータバー。

変調量はノブの移動量で計算されます。対数スケールのターゲット（ディレイタイム、グレインのサイズや密度など）では、変調の幅は数値そのものではなくノブの移動距離に従います。VISUAL の RANDOM はトリガーの割り当て先として使えます。第 10 章を参照してください。

RANDOM と GLIDE TIME

4 つのステーション列の右にある RANDOM ボタン、GLIDE TIME の見出し、HOURS、MINUTES、SECONDS の 3 本のバー。画像は旧バージョンの画面です。現在のレイアウトは下の説明を参照してください。

RANDOM と GLIDE TIME はページ上段、4 つのステーション列の右、MIX バーの隣にあります。どちらも VISUAL ページ全体に働き、ステーションのオン・オフには関係なく使えます。

RANDOMオンになっているステーションの連続パラメータをすべて、RANGE で設定した区間内のランダムな値にします。MIX バー、WARP SPEED、GLIDE TIME は変わらず、オフのステーションは対象外です。区間の初期値は RANGE 追加前の RANDOM の範囲と同じで、たとえば各ステーションの BRIGHTNESS は 1 から 4、FEEDBACK の SMOOTH と BRIGHT はそれぞれ 0 から 0.3、4 つのステーションの WARP DEPTH はそれぞれ 0 から 0.3 です。SMOOTH、BRIGHT、WARP DEPTH の区間の上限は最大 0.3 です。区間をどう設定しても、SMOOTH と BRIGHT の合計は 0.3 以下、4 つの WARP DEPTH の合計は 0.3 以下になります。MESH がオンで内蔵モデルを使っているときは、別の内蔵モデルにも即座に切り替わります。読み込んだ .obj モデルは置き換えられません。変わるのはベース値だけで、MOTION と MOD ROUTE の値はそのままです。PERFORM のツールバーと PERFORM VISUAL ウィンドウの RANDOM も同じ区間を使います。RANDOM は MIDI コントローラーから押せます：LEARN をオンにし、RANDOM をタップしてからコントローラーを操作します。PERFORM ページにもボタン型のコントロールとして置けます（GLOBAL グループの VISUAL RANDOM）。MOD ROUTE からも RANDOM を起動できます。MOD モードで VISUAL ページまたは PERFORM のツールバーの RANDOM をタップすると、OFF と 15 のソースを持つ MOD ROUTE パネルが開き、AMOUNT の位置に「TRIGGER >= 5V」と表示されます。ソースが下から 5 V を超えるたびに 1 回起動します。この設定はアプリ全体で共通です。
RANGEVISUAL ページの RANDOM の右にあるスイッチで、各パラメータが RANDOM で選ばれる区間を設定します。オンにすると、RANDOM の対象になるバーがその場で区間バーに変わり、バーの面にパラメータ名と「下限 - 上限」が表示されます。MIX や WARP SPEED など RANDOM の対象でないバーは変わりません。CHROMASCOPE の LEVEL 1 から 8 は 8 本の縦の区間バーになり、1 本の指で横になぞって設定できます。ドラッグすると、押した位置に近い方の端だけが動き、もう一方の端を越えません。ダブルタップで初期の区間に戻ります。もう一度 RANGE を押すと終了し、バーは元の操作に戻ります。区間はほかの VISUAL パラメータと同じく端末側に保存され、バンク、プロジェクト、SETUP PRESET には含まれません。RANGE は VISUAL ページだけにあり、PERFORM VISUAL ウィンドウにはありません。RANGE 自体は MIDI や PERFORM に割り当てできません。RANGE があるときは、GLIDE TIME の見出しは時間のセルの上に表示されます。
GLIDE TIMEMINUTES（0 から 999）と SECONDS（0 から 59）の 2 つのセル。横にドラッグして値を決めます。ドラッグせずにタップすると、キーボードで数値を入力できます。合計は 2 つの和です。パラメータは現在の値からランダムな値へこの時間をかけて滑らかに移り、その間 GLIDE TIME にはカウントダウンが表示されます。MESH のモデルは即座に切り替わります。MOD ROUTE、MIDI Learn、PERFORM ページが扱うのは合計の秒数で、最大 86400 秒です。
WARP SPEED0 から 1、初期値 1。以前の MAX SPEED です。RANDOM では変わりません。

12. MIDI Learn

トランスポートの MIDI をオンにした状態。割り当て可能なコントロールが破線枠で示される。図は VOICE ページ。

開始と終了

  • トランスポートの MIDI または Cmd+L で開始します。割り当てできるコントロールに破線の枠が表示されます。XY pad には 2 つの角が表示され、左上の角が Y 軸、右下の角が X 軸です。
  • もう一度 MIDI または Cmd+L を押すと終了します。MOD を押しても終了します。ESC では MIDI Learn モードは終了しません。
  • 1.3.4 以降に追加された割り当て先：MIXER の PAN、FX CHAIN の各パラメータ、DRY WET、RETURN、エフェクトの種類（トリガーごとに次の種類へ切り替え）、FREEZE、HOLD（押している間だけ作用）。
  • 1.4.9 で追加された割り当て先：MIXER の MASTER / A1 / A2 / A3 バスボタン、LEVEL FOLLOW。
  • 1.4.10 から 1.4.29 で追加された割り当て先：BPM の PROBABILITY、TRACK DELAY と TRACK DELAY SYNC、LFO の WAVEFORM と SHAPE、SEQUENCER 全体の SYNC、<< / >>（PREVIOUS / NEXT PROGRAM）、ドラムレーンの MUTE。PERFORM と KEYBOARD には GLOBAL グループの新しい割り当て先もあります。第 8 章を参照してください。

手順

  1. コントロールをタップして待機状態に入ります。SETUP の CURRENTLY LEARNING にターゲットが表示されます。待機中のコントロールは黒地にアクセント色の枠で、WAITING と表示されます。
  2. 10 秒以内に MIDI メッセージを送ります。別のコントロールをタップするとターゲットが切り替わります。
  3. 最初に一致したメッセージで割り当てが完了します。ボタンは MOMENTARY、その他は連続値で、カーブの初期値は LINEAR です。既存の割り当ては置き換えられます。新しい割り当ての TAKEOVER は、連続値が PICKUP、ボタンが JUMP になります。

メッセージの種類

割り当て可能CC、Note、Pitch Bend。
割り当て不可Program Change。Aftertouch と SysEx は無視されます。

割り当ての動作

MODELATCH または MOMENTARY です。
TAKEOVERJUMP は新しい値に直接移動し、PICKUP は現在の値を通過してから引き継ぎます。
SCALELINEAR、EXP、LOG。
MIN / MAXマッピング範囲です。
ページ切り替え6 つのページにそれぞれ 1 つのメッセージを割り当てできます。

割り当てはアプリ全体で 1 組を共有し、プロジェクトスロットを切り替えても変わりません。.honki ファイルの書き出しには含まれますが、読み込み時は無視されます。CLOCK IN、ENV DELAY、RECORDING TRACKS、GENERATE VELOCITY、MOD OUTPUT のチャンネルなどの SETTINGS 系の設定も、スロットの切り替え、読み込み、CLEAR、UNDO で保持されます。各パラメータに持てる割り当ては 1 つだけです。

14. 録音

マルチトラック録音

録音する項目は SETUP の SYSTEM タブで選ぶ。RECORDING TRACKS の 16 個のスイッチ、1 分あたりの推定書き込み量、VIDEO RECORDING の RECORD APP SCREEN と RECORD VISUAL OUTPUT。
開始PLAY を押し、Y / REC? / N で Y を選びます。開始前にストレージの空き容量を確認します。録音できる時間が 10 分未満のときは「Low Storage」が表示され、RECORD ANYWAY または CANCEL を選べます。1 分未満のときは「Not Enough Storage」が表示され、録音は始まりません。
停止赤い点の録音停止ボタンを押して Y を選びます。アプリをバックグラウンドに移しても録音は停止しません。システムのオーディオが中断されるとファイルはいったん終了し、復帰後に新しいセッションが始まります。サンプルレートを変更しても新しいセッションが始まります。
連続性長時間の録音で途中が抜けることはなくなりました。ディスクへの書き込みを分散し、MASTER と外部入力のファイルが後回しにならないようにしています。外部入力のルーティング変更やフォアグラウンドへの復帰などでセッション中にオーディオエンジンが再起動した場合、止まっていた時間はすべてのファイルに無音として埋められるため、ファイルの長さは揃ったままで、映像の録画も同じファイルに続けて書かれます。ルーティング変更で増減する外部入力のファイルは、進行中のセッションの中で追加または終了されます。
Recording Stoppedファイルを作成または書き込みできないとき、ストレージがいっぱいのとき、ファイルが WAV の最大サイズに達したときは録音が停止し、REC が解除され、「Recording Stopped」というタイトルの通知に原因が表示されます。たとえば「Recording stopped because a recording file could not be written. The audio recorded up to that point has been saved.」や「Recording could not start because the recording files could not be created.」などです。それまでに書き込まれた内容はセッションフォルダに残ります。再生は続きます。録音中、録音できる時間が 2 分未満になると「LOW STORAGE: ABOUT N MINUTES OF RECORDING LEFT」と表示されます。30 秒未満になると録音は正常に終了し、「Recording Stopped」が表示されます。ストレージがいっぱいで止まったときは、説明が「Disk full.」で始まります。
RECORDING TRACKSSETUP の SYSTEM タブで、書き出す項目を 16 個のスイッチで選びます：TRACK 1 から 8、MASTER、EXTERNAL INPUT、AUX 1、AUX 2、AUX 3、DELAY、REVERB、FX CHAIN。出荷時は TRACK 1 から 8、MASTER、EXTERNAL INPUT がオンです。ALL ON、ALL OFF、LOAD DEFAULT、SAVE DEFAULT もあります。選択はプロジェクトとともに保存されます。プロジェクトに記録がない場合は、SAVE DEFAULT で保存した既定値を使います。録音中は変更できません。下に 1 分あたりの書き込み量の目安が表示されます。すべてオフのときは「Nothing selected. Recording is unavailable.」と表示され、Y を選んでも再生のみになります。
ファイルWAV（32 ビット浮動小数点）：track1 から track4 はモノラル、track5 から track8 はステレオ、master はステレオ。aux1 から aux3 はモノラル。delay と reverb はステレオで、エフェクトリターンの信号です。取り出し点はマスター FILTER と MASTER VOLUME の前です。EXTERNAL INPUT がオンのとき、外部入力のルーティングがあるトラックは trackN_ext.wav も保存します。トラックの取り出し点はフェーダー後です。
VIDEO RECORDINGSETUP の SYSTEM タブに RECORD APP SCREEN と RECORD VISUAL OUTPUT の 2 つのスイッチがあり、初期値はどちらも OFF です。設定はデバイスに保存され、プロジェクトには含まれません。録音中は変更できません。録画は録音と同時に始まり、同時に終わります。動画は同じセッションフォルダに保存されます。
AppScreen.mp4RECORD APP SCREEN がオンのとき、アプリの画面を録画します。マイクは使いません。開始時にシステムの同意ダイアログが表示されます。拒否しても録音には影響しません。アプリ画面の録画は iPad 版だけです。Mac 版で録画できるのは VISUAL の出力だけです。
VisualOutput.mp4RECORD VISUAL OUTPUT がオンのとき、VISUAL の出力画面を録画します：H.264、1280 x 720、30 fps、縦横比を保って縮小し黒帯を加え、MASTER の音声（AAC 192 kbps）付きです。映像エンジンが起動していないときは自動で起動します。VISUAL が OFF のときは録画しません。失敗したときは同じフォルダに VisualOutput.error.txt が書き出されます。
場所Recordings/Sessions/日付-時刻/。同じ秒に重複したときは -2、-3 が付きます。iPad ではファイルアプリの On My iPad / HONKI / Recordings から取得します。Mac では SETUP で選んだ録音フォルダ内の Sessions に保存されます。
