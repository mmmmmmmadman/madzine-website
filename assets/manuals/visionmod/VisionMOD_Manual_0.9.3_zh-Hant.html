1. 概述

Vision MOD 是 macOS 與 Windows 上的即時視覺合成器。它借用模組合成器 Complex Oscillator 的概念：兩個振盪器中以其中一個塑形另一個。Modifier 素材提供動態，Carrier 素材是被這動態承載的影像；以一段素材去調變另一段素材，產生新的影音現象。

源頭之後的每一站都作用於這條合成後的 Carrier 視覺流。去背只在素材源頭（Fundamental Vision）發生；自此之後無內容的區域 alpha 為 0，下游每一站都會丟棄這些像素，因此整條鏈都維持去背狀態。

大視窗尺寸下的主控制視窗：top bar、並排成格狀的各模組面板、Fundamental Vision 下方的全域動作列與 Contour Scanner、CV Generator 區塊，以及固定在右下角的預覽。

2. 訊號流

訊號鏈由主視窗左側的訊號流列表定義。Fundamental Vision 為固定的素材起點（鎖在第一站），其他模組由使用者自由加入、排序、bypass、刪除。拖曳 grip icon 排序、點 X icon 兩次刪除、勾選框個別 bypass。同一種模組可加入多份 instance，各自獨立記憶參數，由上而下串接執行。

訊號流列表。點一列即在模組面板顯示該模組的參數。每列有 grip icon、X icon、啟用勾選框，以及共用的 mix、bright 與 Position 控制。
Signal Flow訊號流（Signal Flow）：模組列表，由上而下依序執行；同一種模組可加多份獨立 instance，各自參數獨立
Drag to reorder拖曳排序：按住 grip icon 上下拖即可改變該 instance 在訊號流中的位置（基礎視覺固定第一站，不可移動）
Remove刪除模組：點一次後該列顯示「確認?」，再點一次同一個 X 即刪除；點其他地方或按 Esc 取消
Enable啟用該 instance：取消勾選即 bypass（訊號直通至下一站），不影響參數與順序。例外：Stable Diffusion 取消時會釋放模型；Slow Motion 重新勾選時清空已錄內容並重錄
Previous module切換到訊號流中的上一個模組面板（在第一個時跳到最後一個）
Next module切換到訊號流中的下一個模組面板（在最後一個時跳到第一個）
Preview預覽：點擊在「目前模組的效果」與「最終輸出」之間切換；遮罩面板開啟時改為在此繪製遮罩

+ Module

+ Module 按鈕開啟模組庫。可加入的模組：Stable Diffusion（Windows 版為 Stream Diffusion）、Minimalize、Chromascope、3D 物件、粒子、Flow Warp、Feedback、3D 模型、慢動作、外掛。Stable Diffusion 只能有一份，已在鏈中時該項目反灰。基礎視覺為固定起點，不能加入也不能刪除。

Module item點選即把該模組加到訊號流最後面並啟用；灰色表示該模組只能有一個且已存在

各站共通控制

Fundamental Vision 之後的每一站共用相同的標頭控制：啟用勾選框、Mix、Brightness 與 Position / Scale 拖曳區。Mix 是該站的 dry/wet，也是唯一的混合控制，模組內沒有自己的 mix 推桿。新加入的 instance Mix 從 0 開始，因此加入模組當下不會改變畫面，拉高 Mix 才會生效。

模組面板（圖為 3D Model）。標頭列有啟用勾選框與 RESET；Mix、Brightness 與 Position / Scale 拖曳區為所有站共用。

4. Contour Scanner 與 CV Generator

主視窗在模組面板下方固定顯示 Contour Scanner 與 CV Generator。掃描器從畫面偵測輪廓；CV Generator 把掃描、動態與顏色轉成調變訊號。全域動作列（PRESET、PLUGINS、OUTPUT、視覺重啟、說明書、說明）位於 Contour Scanner 面板頂端。

模組面板下方的 Contour Scanner 與 CV Generator 區塊。

Contour Scanner

Module輪廓掃描模組：從畫面偵測輪廓，產生 SEQ 訊號與輪廓疊加顯示
Preview輪廓預覽：輪廓線 + 掃描點 + 可拖曳的掃描範圍圓（ROI）
Scan ROI掃描範圍圓：拖曳圓心移動掃描錨點，拖曳圓邊調整掃描範圍
Threshold輪廓邊緣偵測門檻：值越高只保留越強的邊緣
Smoothing輪廓時間平滑：數值為新畫面的比重，越低輪廓變化越慢越穩，100 為不平滑
StillnessStillness：輪廓更新閘門（非邊緣偵測門檻）：畫面要變化超過本值百分比才重新偵測輪廓。調高則輪廓保持得更靜止、CPU/GPU 負擔更低；調低反應更靈敏，調 0 則幾乎每幀都重算

5. Stable Diffusion

把輸入影像轉成 AI 生成畫面。macOS 使用 Stable Diffusion 1.5 + ControlNet + Hyper-SD15 1-step LoRA（Metal）；Windows 使用 Stream Diffusion（CUDA / TensorRT）。鏈中只能有一份 Stable Diffusion。乾濕比例由該站的 Mix 控制；Enable 未勾選時 Mix 強制為 0，訊號鏈不會收到空的 AI 畫面。

Stable Diffusion 面板：Enable、Grayscale、Likeness、Preset、Prompt、LoRA。
Enable啟用 Stable Diffusion：勾選後載入模型，把上一個模組的輸出即時轉成 AI 生成影像；取消即釋放。每次勾選 Mix 從 0 開始，需自行推高才看得到效果；prompt 會保留
Grayscale強制 AI 輸出灰階去色
LikenessAI 輸出貼合上一個模組輸出畫面結構的程度（高=越像輸入畫面）
Preset切換內建風格 prompt（29 種畫風/材質）
PromptAI 生成的文字提示（描述想要的畫面風格）
LoRA選擇 LoRA 檔（.safetensors）套用到 Stable Diffusion（Windows 版為 Stream Diffusion）
LoRA X清除已選的 LoRA 檔，不使用 LoRA
StatusSD 服務狀態：啟動中顯示 SD Loading，完成後顯示使用中的加速後端

取消再勾選 Enable、重開程式、LOAD 之後，prompt 都會保留。重開程式或 LOAD 之後 Stable Diffusion 一律為關閉，勾選後 Mix 從 0 開始。LoRA 檔找不到或沒有讀取權限時，LoRA 列會顯示提示，生成時不套用該 LoRA；重新選擇檔案後提示消失。

6. Chromascope

在畫面上疊加八層，每層對應一條音訊輸入。Base Hue 設定起始色相，Hue Spread 決定各層色相分布。Curve 與 Angle 設定第一層，各自的 Spread 為每層的增減量。各層依上一個模組輸出的亮度分層，不是等分畫面。Level 1 到 8 設定各層亮度，調到 0 該層移除。乾濕比例由該站的 Mix 控制。

Chromascope 面板：Audio、Base Hue、Hue Spread、Curve 與 Angle 及其 Spread，以及 Level 1 到 8 推桿。
Enable啟用 Chromascope 色彩效果
AudioChromascope 波形倍率（0 到 5）：0 無線條；3 以下為純倍率；3 到 5 把波形整體上抬，線條由窄變寬
Base HueChromascope 基準色相
Hue SpreadChromascope 八層之間的色相分散範圍：第 k 層色相 = 基準色相 + 分散 × k / 有效層數
CurveChromascope 第一層的波形彎曲程度；值越大線條越稀、彎曲集中在中間
Curve SpreadChromascope 每往下一層彎曲程度的增減量（正負）：第 k 層 = 彎曲 + k × 本值
AngleChromascope 第一層的波形方向角度（0 到 360 度）
Angle SpreadChromascope 每往下一層角度的增加量：第 k 層 = 角度 + k × 本值
Level 1 to 8Chromascope 該層亮度，對應同編號音訊輸入軌；各層依上一個模組輸出的亮度分層（不是等分畫面）；調到 0 該層移除，其餘層重新分配亮度區間

7. Minimalize

以追蹤的種子點把畫面重建成多邊形。Mode 可選 Triangle（Delaunay 網格）、Cell（Voronoi）或 Square（Quadtree 矩形）；Fill 切換填滿多邊形或只畫邊線。多邊形顏色取自訊號鏈輸入，Modifier 只用來位移種子點。

Minimalize 面板：Density、Mode、Fill、Displace、Smooth、Line Color、Line Width、Line Sat、Fill Sat。
Enable啟用 Minimalize：把上一個模組的輸出依 seed 點重新切割成多邊形（Voronoi／Delaunay／Quadtree）
Densityseed 點數量上限（0-500）；數值越高多邊形越細
Mode切割拓樸：Triangle（Delaunay 三角網格）／Cell（Voronoi 細胞）／Square（Quadtree 矩形）
Fill切換填色：勾選後多邊形以 Fill Sat 飽和度填色，未勾僅顯示邊線（線框模式）
Displaceseed 點依 Modifier 影像 R/G 通道作 2D 位移（Image Displace 例外路徑：Modifier 此處為位移向量源，不作紋理採色）；0 關閉，值越大多邊形破碎晃動越明顯
Smoothseed 點時間平滑：高值抑制 LK 追蹤抖動，但會降低對畫面變化的反應速度
Line Color多邊形邊線顏色：Line Sat 為 0（預設）時，0 到 0.5 由黑變白，0.5 以上都是白；Line Sat 大於 0 時，0 為黑、0.5 為該色相、1 為白
Line Width多邊形邊線寬度（0–5，0 為不畫線）
Line Sat邊線飽和度（0 為黑/灰，1 為純色相色）
Fill Sat填色飽和度（Fill 未勾選時無視覺效果）

8. 3D Object（3D 物件）

Smooth融合平滑（0–5）：0 為單一形狀；大於 0 時加入第二顆小球並與主形狀融合，值越大越平滑
