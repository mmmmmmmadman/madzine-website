1. 概要

Vision MOD は macOS と Windows で動作するリアルタイム映像シンセサイザーです。モジュラーシンセサイザーの Complex Oscillator——一方のオシレーターでもう一方を整形する仕組み——を映像領域に持ち込みます。Modifier の素材がダイナミクスを与え、Carrier の素材はそのダイナミクスに乗る映像。ある映像素材が別の映像素材を変調し、新しい視聴覚現象が生まれます。

ソース以降の各 station はこの合成された Carrier 映像流に対して動作します。背景除去は素材の起点（Fundamental Vision）でのみ行い、それ以降、内容のない領域は alpha 0 を保持し、下流の各 station はそのピクセルを破棄するため、チェーン全体で被写体の切り抜きが維持されます。

メインコントロールウィンドウ：トップバー、選択中モジュールのパラメータパネル、Contour Scanner と CV Generator ブロック、右側のモジュールパネル。

2. シグナルフローとモジュールパネル

パイプラインはメインウィンドウ右側のモジュールパネルで定義します。Fundamental Vision はソースアンカーとしてスロット 1 に固定、それ以外のモジュールはユーザーが追加・並べ替え・bypass・削除を行います。grip アイコンをドラッグして並べ替え、X アイコン（2 クリック確認）で削除、チェックボックスで個別 bypass。同種のモジュールを複数 instance 化でき、各 instance は独立したパラメータで上から下へ直列接続されます。

+ Module

各 station 共通コントロール

Fundamental Vision 以降の各 station は同じヘッダーコントロールを共有します：有効チェックボックス、Mix、Brightness、Position / Scale パッド。Mix はその station の dry/wet で、唯一のミックスコントロールです。モジュール内に独自の mix フェーダーはありません。新規追加した instance の Mix は 0 から始まるため、追加した時点では画面は変わらず、Mix を上げると効果が現れます。

4. Contour Scanner と CV Generator

メインウィンドウのモジュールパネルの下には常に Contour Scanner と CV Generator が表示されます。スキャナーは映像から輪郭を検出し、CV Generator はスキャン・動き・色をモジュレーション信号に変換します。グローバル操作行（PRESET、PLUGINS、OUTPUT、ビジュアル再起動、ヘルプ）は Contour Scanner パネルの上部にあります。

Contour Scanner

Preview輪郭プレビュー：ライブ映像＋輪郭線＋ドラッグ可能な走査範囲円（ROI）

5. Stable Diffusion

入力映像を AI 生成映像に変換します。macOS は Stable Diffusion 1.5 + ControlNet + Hyper-SD15 1-step LoRA（Metal）、Windows は Stream Diffusion（CUDA / TensorRT）で実行します。チェーン内の Stable Diffusion は 1 つのみ。dry/wet は station の Mix で制御し、Enable が未チェックの間は Mix が 0 に固定されるため、チェーンに空の AI フレームが流れることはありません。

Stable Diffusion パネル：Enable、Grayscale、Likeness、Preset、Prompt、LoRA。
EnableStable Diffusion を有効化：モデルを読み込みカメラ映像を AI 生成に変換、解除で解放
GrayscaleAI 出力をグレースケールに強制します
LikenessAI 出力がカメラ構造に沿う度合い（高い＝カメラに近い）
Preset内蔵スタイルプロンプトを切替（29 種の画風／質感）
PromptAI 生成のテキストプロンプト（望む画風を記述）
LoRAStable Diffusion 用の LoRA ファイル（.safetensors）を選択。クリアで LoRA を無効化。未設定時は No LoRA と表示されます。
StatusSD サービス状態：起動中は SD Loading、完了後は使用中のアクセラレーションを表示

6. Chromascope

映像に 4 つのカラーチャンネルを重ねます。Base Hue が開始色相、Hue Spread がそれを中心とした 4 チャンネルの分布を決め、各チャンネルに独自の Curve と Angle があります。dry/wet は station の Mix で制御します。

Chromascope パネル：Base Hue、Hue Spread、各チャンネルの Curve と Angle フェーダー。
EnableChromascope カラー効果を有効化
Base HueChromascope 基準色相
Hue SpreadChromascope 各チャンネル間の色相の広がり
CH 1 to 4 CurveChromascope このチャンネルのカラーカーブ
CH 1 to 4 AngleChromascope このチャンネルの色相回転角

7. Minimalize

追跡したシード点から映像をポリゴンに再構成します。Topology で Triangle（Delaunay メッシュ）、Cell（Voronoi）、Square（Quadtree 矩形）を選択。Fill でポリゴン塗りつぶしとエッジのみのワイヤーフレームを切り替えます。ポリゴンの色はチェーン入力からサンプリングし、Modifier はシード点の変位にのみ使われます。

Minimalize パネル：Density、Topology、Fill、Displace、Smooth、Line Color、Line Width、Line Sat、Fill Sat。
EnableMinimalize ステージ有効化：Chromascope 出力を seed 点で多角形（Voronoi／Delaunay／Quadtree）に再分割
Densityseed 点の上限数（2-1500）。数値が大きいほど多角形が細かくなる
Topology分割トポロジー：Triangle（Delaunay 三角網）／Cell（Voronoi 細胞）／Square（Quadtree 矩形）
Fill塗りつぶし切替：オンで Fill Sat の彩度で多角形を塗りつぶし、オフでは輪郭線のみ（ワイヤフレーム）
Displaceseed 点を Modifier 映像の R/G チャンネルで 2D 変位（Image Displace 例外経路：Modifier は変位ベクトル源として作用、テクスチャ採色はしない）。0 で無効、大きいほど多角形の揺らぎが強くなる
Smoothseed 点の時間平滑：高い値は LK 追跡のジッターを抑えるが、映像変化への応答が遅くなります
Line Color多角形の輪郭線の色相（0–1 が 0–360° に対応）
Line Width多角形の輪郭線の太さ（ピクセル）
Line Sat輪郭線の彩度（0 で黒／グレー、1 で純色相）
Fill Sat塗りつぶしの彩度（Fill オフ時は視覚的に無効）

13. Slow Motion（スローモーション）

入力映像を 30 fps でセグメントに録画し、遅い速度でループ再生します。Buffer 秒数分を録画するとセグメントがロックされます。Buffer フェーダーをドラッグするか、station をオフ・オンすると新しいセグメントを取り込みます。

Speed再生速度（0.05–1、1 = 原速）：映像は固定 30fps で録画し、30 × この値の速度で再生。0.25 = 4 倍スローモーション。セグメントが満杯になるとループ再生
Bufferセグメント長（0.5–15 秒）：30fps で N 秒録画した時点でセグメントを固定しループ再生。このフェーダーを操作するか、本ステーションをオフ→オンで再取得。大きいほど VRAM 使用量が増加
Blendフレーム補間：隣接する 2 枚の録画フレーム間を補間し、スローモーションを滑らかに保つ。オフではコマ飛び再生になる

14. Plugin（プラグイン）

サードパーティの fragment shader を station として実行します。プラグインは単一の .wgsl ファイルで、プラグインフォルダ（既定 ~/.visionmod/plugins/、最上位のみ）から読み込みます。フォルダはメインウィンドウの PLUGINS 行で選択し、変更時に自動で再スキャンされます。このバージョンでは Plugin パネルにパラメータは表示されません。フォルダ内で最初にコンパイルに成功したプラグインが使われ、失敗したプラグインはスキップされて station は映像をそのまま通過させます。

プラグインファイルのヘッダー

メタデータはファイル先頭の //! コメント行ブロックに記述します。api と name.en は必須。name.zh、name.ja、author、description、url、param 行は任意です。解析は //! コメントでない最初の行で停止します。プラグイン id はファイル名の小文字なので、ファイル名を変えると別のプラグインとして扱われます。

  • //! api = 1
  • //! name.en = My Effect
  • //! param0 = amount | 0.0 | 1.0 | 0.5 | mod | Amount（id、最小、最大、既定、mod または -、ラベル）

15. グローバル操作

Contour Scanner パネル上部の操作行はプログラム全体に作用します。

PRESETSAVE AS で現在の全パラメータをファイルに保存。LOAD でファイルを読み込みます。読み込みは現在の全パラメータを上書きし取り消せないため、先に「上書き読込 / キャンセル」の確認が表示されます。
PLUGINSCHOOSE でフォルダピッカーを開きプラグインフォルダを指定。DEFAULT で既定フォルダに戻ります。2 行目に使用中のフォルダ、ない場合は「利用できるフォルダなし」と表示されます。
OUTPUT+ WINDOW でチェーン末端を表示する出力ウィンドウを開きます。出力ウィンドウは切り抜き、パン、ズームが可能です。
View Panicビジュアル再起動：出力ビューポートが固まったとき強制リペイント（GPU リソースはリセットしない）

16. SIGNAL ウィンドウ

トップバーの SIGNAL トグルでフローティングウィンドウを開きます。左列にプレビューと 7 本の CV メーター（Sequence 1 / 2、Movement、Color R / G / B / Saturation）。右列に Audio Inputs、CV Output、LFO があります。

SIGNAL ウィンドウ：左に CV メーター、右に Audio Inputs、CV Output ルート、LFO。

CV メーター

Sequence 1SEQ1 シーケンス信号：輪郭上を動く走査点とアンカーの水平距離（0-10V、平滑済み）。塗りが現在の出力値
Sequence 2SEQ2 シーケンス信号：輪郭上を動く走査点とアンカーの垂直距離（0-10V、平滑済み）。塗りが現在の出力値
MovementMovement エネルギー：Modifier 全画面のフレーム間輝度差の平均 ×Gain（0-10V、平滑済み）
Color RedModifier 映像の平均赤量（0-10V）。モジュレーションソース／CV 出力に使用可
Color GreenModifier 映像の平均緑量（0-10V）。モジュレーションソース／CV 出力に使用可
Color BlueModifier 映像の平均青量（0-10V）。モジュレーションソース／CV 出力に使用可
Color SaturationModifier 映像の平均彩度（HSV S、0-10V）。モジュレーションソース／CV 出力に使用可

Audio Inputs

CardAudio Inputs：4 トラックの音声入力レベル（RMS）をモジュレーションソースに
Deviceオーディオ入出力デバイスの選択
Channelこのトラックが入力デバイスのどのチャンネルを読むか
Meterこのトラックの入力レベルメーター（ピーク）。上端の色線は同番号の Chromascope チャンネル色に対応

CV Output

Output ドロップダウンでオーディオ出力デバイスと MIDI 出力ポートをまとめて選択します。各ルートでソース信号、オーディオ出力チャンネル、MIDI CC 番号を選びます。

CardCV Output：モジュレーション信号をオーディオ出力チャンネル（ch3 以降）と MIDI デバイスへ送出
Sourceモジュレーション信号のルート元；オーディオ出力チャンネルと MIDI デバイス（ルートごとの CC#、14bit）へ同時に出力
Chこの CV 信号を音声出力デバイスのどのチャンネルへ送るか（MIDI 側は右の CC# で指定）
CCこのルートの MIDI CC 番号（0-127）。14bit で送出（MSB=CC、LSB=CC+32）、CC>95 は 7bit に降格
Clock設計上の制約：CV クロックは音声出力コールバックで駆動。出力デバイス未選択時は CV と走査／メーター／映像が停止

LFO

LFO 1 to 4内蔵 LFO 1〜4。各行に波形ボタン（クリックで Sine、Triangle、Square、Saw を循環）と Hz のレート値（0.01〜20。ドラッグで調整、ダブルクリックでキーボード入力）。モジュレーションソース LFO 1〜4 として使用できます。

17. モジュレーションと MIDI Learn

モジュレーション可能なフェーダーはラベル左に小さな点があります。左クリックで接続のオン／オフ、右クリックでポップアップを開き、グリッドから Source を 1 つ選んで Amount を設定します。Amount はバイポーラ（-1〜1、中心 0）で、ソースはパラメータをどちらの方向にも動かせます。各パラメータは 1 本の接続を保持します。

モジュレーションソース信号は映像、音声、内蔵 LFO から連続生成されます。
モジュレーション点を右クリックしてポップアップを開き、ソースを選んで Amount をドラッグします。

ソース

Sequence 1 / 2輪郭スキャン信号。Smooth Sequence 1 / 2 は平滑化版。
Audio Input 1 to 4 RMS4 トラックの音声入力レベル。
Movement前景の動きエネルギー。Movement Smooth は平滑化版。
Color Red / Green / Blue / SaturationModifier フレームの平均色。
LFO 1 to 4SIGNAL ウィンドウで設定する内蔵 LFO。

MIDI Learn

MIDI 対応フェーダーは値の右にバインディング点があります。右クリックして MIDI Learn を選び、MIDI 機器のコントロールを動かすとバインドされ、点がアクセント色になります。同じメニューにバインド済みのチャンネルと CC が表示され、Clear Binding も選べます。学習対象は 7-bit Control Change のみです。
