1. 概要

Vision MOD は macOS と Windows で動作するリアルタイム映像シンセサイザーです。モジュラーシンセサイザーの Complex Oscillator——一方のオシレーターでもう一方を整形する仕組み——を映像領域に持ち込みます。Modifier の素材がダイナミクスを与え、Carrier の素材はそのダイナミクスに乗る映像。ある映像素材が別の映像素材を変調し、新しい視聴覚現象が生まれます。

ソース以降の各 station はこの合成された Carrier 映像流に対して動作します。背景除去は素材の起点（Fundamental Vision）でのみ行い、それ以降、内容のない領域は alpha 0 を保持し、下流の各 station はそのピクセルを破棄するため、チェーン全体で被写体の切り抜きが維持されます。

メインコントロールウィンドウ：トップバー、選択中モジュールのパラメータパネル、Contour Scanner と CV Generator ブロック、右側のシグナルフロー一覧。

2. シグナルフロー

パイプラインはメインウィンドウ右側のシグナルフロー一覧で定義します。Fundamental Vision はソースアンカーとしてスロット 1 に固定、それ以外のモジュールはユーザーが追加・並べ替え・bypass・削除を行います。grip アイコンをドラッグして並べ替え、X アイコン（2 クリック確認）で削除、チェックボックスで個別 bypass。同種のモジュールを複数 instance 化でき、各 instance は独立したパラメータで上から下へ直列接続されます。

各 station 共通コントロール

3. Fundamental Vision（基礎ビジョン）

ソース station。左に Modifier、右に Carrier の 2 スロットが並びます。各スロットにはカメラ、動画ファイル、写真を割り当てられます。Modifier は Color 信号、各モジュールの Displace、Flow Warp の流れ場の元になり、Carrier がチェーンに送られる映像本体です。

Fundamental Vision：Modifier（左）と Carrier（右）、その間に Mix フェーダー。
Module素材入力モジュール：Modifier（左）が Carrier（右）を変調、Mix で両者を合成
ModifierModifier スロット：変調素材。Color CV、粒子 Displace、Flow Warp フロー場のソース
CarrierCarrier スロット：主視覚映像、下流処理チェーンへ流れます
MixCarrier と Modifier の合成：右へ動かすと Carrier、左で Modifier
BrightnessFundamental Vision の出力輝度（0–1、1 で元の明るさ）
Source typeソース種別：カメラ／動画／写真の三択（動画・写真はドラッグ＆ドロップで読み込み）
Remove background背景除去（3 段階：オフ／人物を残す／反転して背景を残す）：MediaPipe が前景マスクを計算し、Modifier と Carrier を合成した後の映像に適用
Flip Hソース映像を水平反転（左右ミラー）；producer 段階で適用、チェーン全体に反映
Flip Vソース映像を垂直反転（上下ミラー）；producer 段階で適用、チェーン全体に反映
Video speed読み込んだ動画の再生速度（0 停止、1 等速、5 五倍速）

4. Contour Scanner と CV Generator

メインウィンドウのモジュールパネルの下には常に Contour Scanner と CV Generator が表示されます。スキャナーは映像から輪郭を検出し、CV Generator はスキャン・動き・色をモジュレーション信号に変換します。グローバル操作行（PRESET、PLUGINS、OUTPUT、ビジュアル再起動、説明書、ヘルプ）は Contour Scanner パネルの上部にあります。

Contour Scanner

Module輪郭スキャナーモジュール：映像から輪郭を検出し、SEQ 信号と輪郭オーバーレイを生成
Preview輪郭プレビュー：輪郭線＋走査点＋ドラッグ可能な走査範囲円（ROI）
Scan ROI走査範囲円：中心をドラッグで走査アンカー移動、縁をドラッグで走査範囲を調整
Threshold輪郭エッジ検出の閾値：高いほど強いエッジのみ残します
Smoothing輪郭の時間方向スムージング：値は新しいフレームの比重。低いほど変化が遅く安定し、100 でスムージングなし
Scene Threshold輪郭の更新ゲート（エッジ検出の閾値ではありません）：画面がこの値（％）を超えて変化したときだけ輪郭を再検出します。高いほど輪郭は静止したまま保たれ CPU／GPU の負荷も下がり、低いほど反応が速くなり、0 ではほぼ毎フレーム再計算します
Lock現在の輪郭を固定：再検出を停止し、固定した輪郭に沿って走査を続けます
Mix輪郭オーバーレイの合成比率

CV Generator

ModuleCV Generator：映像からモジュレーション信号を生成（輪郭 SEQ、Movement、Color）
Scan Time輪郭走査周期：走査が一巡する時間（0.1-300 秒）。トラック上の白線が現在の走査位置
SmoothSEQ と Movement 信号の平滑度
GainMovement 信号のゲイン（ソース：最終出力画面）
Foreground前景閾値：アルファがこの値を超えるピクセルのみ Movement と Color CV に算入します

5. Stable Diffusion

入力映像を AI 生成映像に変換します。macOS は Stable Diffusion 1.5 + ControlNet + Hyper-SD15 1-step LoRA（Metal）、Windows は Stream Diffusion（CUDA / TensorRT）で実行します。チェーン内の Stable Diffusion は 1 つのみ。dry/wet は station の Mix で制御し、Enable が未チェックの間は Mix が 0 に固定されるため、チェーンに空の AI フレームが流れることはありません。

Stable Diffusion パネル：Enable、Grayscale、Likeness、Preset、Prompt、LoRA。
EnableStable Diffusion を有効化：モデルを読み込み、前のモジュールの出力をリアルタイムで AI 生成映像に変換。解除で解放。チェックするたびに prompt が消去され、Mix は 0 から始まるため、効果を見るには Mix を上げてください
GrayscaleAI 出力をグレースケールに強制します
LikenessAI 出力がカメラ構造に沿う度合い（高い＝カメラに近い）
Preset内蔵スタイルプロンプトを切替（29 種の画風／質感）
PromptAI 生成のテキストプロンプト（望む画風を記述）
LoRAStable Diffusion 用の LoRA ファイル（.safetensors）を選択。クリアで LoRA を無効化。未設定時は No LoRA と表示されます。
StatusSD サービス状態：起動中は SD Loading、完了後は使用中のアクセラレーションを表示

6. Chromascope

映像に 8 層を重ね、各層が 1 つの音声入力に対応します。Base Hue が開始色相、Hue Spread が各層の色相分布を決めます。Curve と Angle は第一層を設定し、それぞれの Spread が層ごとの増減量です。Level 1 から 8 は各層の明るさで、0 の層は外れます。dry/wet は station の Mix で制御します。

Chromascope パネル：Audio、Base Hue、Hue Spread、Curve と Angle とそれぞれの Spread、Level 1 から 8 のフェーダー。
EnableChromascope カラー効果を有効化
AudioChromascope 波形の倍率（0 から 5）：0 で線なし、3 までは倍率のみ、3 から 5 は波形全体を持ち上げ線が太くなります
Base HueChromascope 基準色相
Hue SpreadChromascope 八層間の色相の広がり：第 k 層の色相 = 基準色相 + 広がり × k / 有効層数
CurveChromascope 第一層の波形の曲がり具合；大きいほど線がまばらになり中央で曲がります
Curve SpreadChromascope 層ごとの曲がり具合の増減（正負）：第 k 層 = カーブ + k × この値
AngleChromascope 第一層の波形の向きの角度（0 から 360 度）
Angle SpreadChromascope 層ごとの角度の増加量：第 k 層 = 角度 + k × この値
Level 1 to 8Chromascope この層の明るさ（同じ番号の音声入力に対応）；0 でこの層を外し、残りの層で画面を等分します

7. Minimalize

追跡したシード点から映像をポリゴンに再構成します。Topology で Triangle（Delaunay メッシュ）、Cell（Voronoi）、Square（Quadtree 矩形）を選択。Fill でポリゴン塗りつぶしとエッジのみのワイヤーフレームを切り替えます。ポリゴンの色はチェーン入力からサンプリングし、Modifier はシード点の変位にのみ使われます。

Minimalize パネル：Density、Topology、Fill、Displace、Smooth、Line Color、Line Width、Line Sat、Fill Sat。
EnableMinimalize を有効化：前のモジュールの出力を seed 点で多角形（Voronoi／Delaunay／Quadtree）に再分割
Densityseed 点の上限数（2-1500）。数値が大きいほど多角形が細かくなる
Topology分割トポロジー：Triangle（Delaunay 三角網）／Cell（Voronoi 細胞）／Square（Quadtree 矩形）
Fill塗りつぶし切替：オンで Fill Sat の彩度で多角形を塗りつぶし、オフでは輪郭線のみ（ワイヤフレーム）
Displaceseed 点を Modifier 映像の R/G チャンネルで 2D 変位（Image Displace 例外経路：Modifier は変位ベクトル源として作用、テクスチャ採色はしない）。0 で無効、大きいほど多角形の揺らぎが強くなる
Smoothseed 点の時間平滑：高い値は LK 追跡のジッターを抑えるが、映像変化への応答が遅くなります
Line Color多角形の輪郭線の色：0 で黒、1 で白、中間は色相環に沿って変化
Line Width多角形の輪郭線の太さ（0–5、0 で線を描かない）
Line Sat輪郭線の彩度（0 で黒／グレー、1 で純色相）
Fill Sat塗りつぶしの彩度（Fill オフ時は視覚的に無効）

8. 3D Object（3D オブジェクト）

レイマーチングで描画し、チェーン入力をテクスチャとして貼る 3D オブジェクト。Shape は 5 つのプリミティブ間をモーフィング。Distort、Repeat、Spacing、Jitter、Smooth で形状を整え、Zoom、Pan、Tilt でカメラを動かします。Displace は Modifier の輝度で表面を押し出します。

Enable3D Object を有効化：SDF レイマーチによる立体オブジェクト描画
RESET3D Object の全パラメータをデフォルトに戻します
Shape3D オブジェクト形状：5 種のプリミティブ（球／箱／トーラス／八面体／ジャイロイド）間でモーフ
Size3D オブジェクトの全体サイズ
Distortドメインワープ（sin ドメイン変形）の強さ
DisplaceModifier 映像の輝度で 3D オブジェクト表面を変位（0 で無効、大きいほど凹凸が深い）
Repeatドメインリピート：空間内で配列複製する量
Spacing複製配列の間隔
Jitter配列のジッター量
Smooth融合の滑らかさ（0–5）：0 は単一形状。0 より大きいと第二の小球が加わり主形状と融合、大きいほど滑らか
Zoomカメラからオブジェクトまでの距離（2–10）
Panカメラの水平周回角
Tiltカメラの俯仰角

9. Triposr 3D（立体再構成）

RESET立体再構成の全パラメータをデフォルトに戻します
Rotate Y3D メッシュの Y 軸回転角（0–360°）
Rotate X3D メッシュの X 軸回転角（0–360°）
Rotate Z3D メッシュの Z 軸回転角（0–360°）
Scale3D メッシュの全体スケール（0.1–5）
DisplaceModifier 映像の輝度でメッシュ頂点を法線方向に変位（0 で無効、大きいほど凹凸が深い）

EnableFeedback 映像フィードバック効果を有効化
Smoothスムーズ量：前フレームと混ぜる割合。大きいほど残像が長く、0 で残像なし
Bright明部ゲイン（0–1）：0 で増光なし。0.5 未満は残像の明るさに上限あり、0.5 以上は明部がフレームごとに明るくなり白に達する
Chroma色収差量（0–0.005）：赤チャンネルを右、青チャンネルを左へずらす距離。0 でオフ
Diffuse拡散（0–1）：フィードバック映像のぼかし量。0 でぼかしなし、大きいほど残像がにじむ

13. Slow Motion（スローモーション）

入力映像を 30 fps で録画し続け、直近の Buffer 秒数分を保持して遅い速度でループ再生します。Buffer フェーダーをドラッグするか、station をオフ・オンすると録画をクリアして録り直します。

Enableスローモーションを有効化：前のモジュールの出力を録画し、減速してループ再生。オフ→オンで録画をクリアして録り直し
RESETスローモーションの全パラメータをデフォルトに戻します
Speed再生速度（0.05–1、1 = 原速）：映像は固定 30fps で録画し、30 × この値の速度で再生。0.25 = 4 倍スローモーション。直近に録画したセグメント内をループ再生
Bufferセグメント長（0.5–15 秒）：30fps で録画を続け、直近 N 秒を保持してループ再生。このフェーダーを操作するか、本モジュールをオフ→オンでクリアして録り直し。大きいほど VRAM 使用量が増加
Blendフレーム補間：隣接する 2 枚の録画フレーム間を補間し、スローモーションを滑らかに保つ。オフではコマ飛び再生になる

14. Plugin（プラグイン）

サードパーティの fragment shader を station として実行します。プラグインは単一の .wgsl ファイルで、プラグインフォルダ（既定 ~/.visionmod/plugins/、最上位のみ）から読み込みます。フォルダはメインウィンドウの PLUGINS 行で選択し、変更時に自動で再スキャンされます。Plugin パネルにはプラグインを選ぶドロップダウンがあります。「自動」はリスト内で最初に正常に動作するプラグインを使い、コンパイルに失敗したプラグインは状態付きで表示されますが選択できません。その下に内蔵の Displace フェーダー（Modifier 映像で入力映像を変位、0 でオフ）と、選択したプラグインが宣言したパラメータのフェーダーが並びます。使えるプラグインがない場合、station は映像をそのまま通過させます。

Enableプラグインモジュールを有効化：選択したプラグインが前のモジュールの出力を処理。プラグインが使えない場合は映像をそのまま通過
RESETプラグインのパラメータをデフォルトに戻し、すべての変調を切断。プラグインの選択は維持

プラグインファイルのヘッダー

メタデータはファイル先頭の //! コメント行ブロックに記述します。api と name.en は必須。name.zh、name.ja、author、description、url、param 行は任意です。解析は //! コメントでない最初の行で停止します。プラグイン id はファイル名の小文字なので、ファイル名を変えると別のプラグインとして扱われます。

  • //! api = 1
  • //! name.en = My Effect
  • //! param0 = amount | 0.0 | 1.0 | 0.5 | mod | Amount（id、最小、最大、既定、mod または -、ラベル）

16. SIGNAL ウィンドウ

トップバーの SIGNAL トグルでフローティングウィンドウを開きます。左列にプレビューと 7 本の CV メーター（Sequence 1 / 2、Movement、Color R / G / B / Saturation）。右列に Audio Inputs、CV Output、LFO があります。

SIGNAL ウィンドウ：左に CV メーター、右に Audio Inputs、CV Output ルート、LFO。

CV メーター

ModuleCV Meter：映像から生成した 7 本のモジュレーション信号を表示（輪郭 SEQ 1／2、Movement、Color R／G／B／Sat）

Sequence 2SEQ2 シーケンス信号：輪郭上を動く走査点とアンカーの垂直距離（0-10V、平滑済み）。塗りが現在の出力値

Color RedModifier 映像の平均赤量（0-10V）。モジュレーションソース／CV 出力に使用可
Color GreenModifier 映像の平均緑量（0-10V）。モジュレーションソース／CV 出力に使用可
Color BlueModifier 映像の平均青量（0-10V）。モジュレーションソース／CV 出力に使用可

17. モジュレーションと MIDI Learn

モジュレーション可能なフェーダーはラベル左に小さな点があります。左クリックで接続のオン／オフ、右クリックでポップアップを開き、グリッドから Source を 1 つ選んで Amount を設定します。Amount はバイポーラ（-1〜1、中心 0）で、ソースはパラメータをどちらの方向にも動かせます。各パラメータは 1 本の接続を保持します。

モジュレーションソース信号は映像、音声、内蔵 LFO から連続生成されます。
モジュレーション点を右クリックしてポップアップを開き、ソースを選んで Amount をドラッグします。
Modulation dotモジュレーションドット：左クリックでこのパラメータの変調を接続／切断（新規接続の量は 0）、右クリックでソースと量の設定を開く
Sourceモジュレーションソース：このパラメータを変調する信号をクリックで選択
Amountモジュレーション量（-1〜1）：0 で変調なし、負の値は反転。ダブルクリックで 0 に戻る

MIDI Learn

MIDI 対応フェーダーは値の右にバインディング点があります。右クリックして MIDI Learn を選び、MIDI 機器のコントロールを動かすとバインドされ、点がアクセント色になります。同じメニューにバインド済みのチャンネルと CC が表示され、Clear Binding も選べます。学習対象は 7-bit Control Change のみです。

MIDI LearnMIDI Learn：クリック後に MIDI コントローラーのノブやフェーダーを動かすと、次に受信した CC がこのパラメータに割り当てられる
Clear BindingClear Binding：このパラメータの MIDI 割り当てを解除
