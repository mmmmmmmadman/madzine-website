MADZINE AU Bundle

iOS, iPadOS, macOS

一個 app 內含四個 AUv3 外掛：MOD HUB、Universal Rhythm、ChaosTrio、Oscilloscope

功能介紹

MADZINE AU Bundle 是一個 app，內含四個 AUv3 外掛，在宿主中顯示為六個項目：MOD HUB（MIDI 版、CV 版）、Universal Rhythm（MIDI 版、內建鼓組版）、ChaosTrio、Oscilloscope。需要支援 AUv3 的宿主 app。

前往 App Store Mac 版即將推出

特色一覽

  • 一個 app 內含四個 AUv3 外掛，在宿主中顯示為六個項目
  • MOD HUB：8 stage 音序器（A / B 兩組 + CROSSFADE）、六個 LFO、DRAW 手繪，混合送到四個輸出（MIDI 版 / CV 版）
  • Universal Rhythm：四角色、九軌道、九種節奏風格，單步調整 velocity / probability / decay / ratchet（MIDI 版 / 內建鼓組版）
  • 鼓組版 sampler：讀取音訊檔、切片、粒子合成播放，MULTI-OUTPUT 分軌輸出
  • ChaosTrio：三個 slot，DELAY / weiii Documenta / KARPLUS，五種接法，Lorenz chaos 調變
  • Oscilloscope：示波器、頻譜參考曲線、FOURIER BOX 3D 顯示，音訊直通
  • 英文 / 繁體中文 / 日文說明模式
  • 黑底 / 白底，可選主要配色
  • 參數可被宿主 automation 與 MIDI CC 控制
